# 规格生产用途与原规则关联交付

2026-10-25。本批解决订单制图准备被未知净重阻断，以及规格不能明确引用原制作规则版本的问题。它是订单到工厂 P3 的一个业务切片；整阶段还须真实订单制作、审核和生产交付证明。

## 可验收行为

- 商品库的单项、批量共用和逐行规格分别显示生产资料核对及完整商品资料确认。
- 生产核对要求明确的材质、结构、生产尺寸口径和必要数值、每份内容/件数、依据及合法已审核通用工艺。未知净重保持空值，不用含包装重量代填。
- 选择当前适用的原制作规则时保存确切规则与版本。可信抱枕工厂规则可通过按钮显式采用图案最长边口径；数字、工艺和确认仍由操作员核对。
- 审单与制造候选使用生产资料条件。商业 SKU、商品制作、套图、刊登及封版继续要求完整商品资料。
- 已停用的原引用在未确认草稿里保留并明确提示，不能借其重新确认。事实、工艺或引用更改后撤销生产确认。
- 数据库前向迁移 0189 同步制造审核和生产绑定的用途条件，原 BOM、物料、工序、审批、原事务和不可变内容门保持。

实现复用现有 React、Zod、PostgreSQL、规则客户端和模块拥有者；未新增服务、依赖或收费调用。详细接口及权限见[规格事实](../integration/specification-facts.md)与[制造版本](../integration/manufacturing-recipes.md)。

## 开发验收

已通过契约 9 例、前端 8 例和隔离 API/SQL 集成 29 例。真实个人登录浏览器共有 5 个不同用例通过，覆盖单项原规则关联、净重未知、批量核对、完整商品确认及失权清理，桌面和 390 像素窄屏已查看。

浏览器检查发现批量勾选被 View Transition 回调延迟，已用可控延迟回归测试复现并修复：确认与引用勾选同步更新，仅尺寸口径布局按钮使用形变过渡。原用例断言保持，两个受影响用例修复后通过。隔离数据库、桶、Redis 和身份服务由运行器 finally 清理。

类型、定向 lint、规则镜像、源秘密扫描和迁移元数据检查通过。以上是开发证据；正式采用还需精确候选的 CI、固定构建、备份/恢复与迁移演练，以及日用页面回查，不能据此提前标记整 P3 完成。
