# POD 模块 PRD 04：侵权检测

## 1. 模块目标

在生成、设计审核、Listing 审核和导出前提供可追溯的权利风险辅助判断，包括基础风险过滤、深度证据检索、视觉相似度、租户内重复检查和印花版本反查。模块不提供法律意见，也不把“低风险”解释为已获得使用权。

公共资产域、版本、审核和导出规则遵循[总 PRD](../2026-08-03-yummyai-pod-workbench.md)。

## 2. 风险检查类型

### 2.1 基础风险过滤

基础检查面向大批量候选图，至少覆盖：

- 已知商标、品牌名称和明显商业标识；
- 配置中的热门角色、影视、游戏、体育和名人 IP；
- 组织禁止元素和平台禁限售关键词；
- 输入资产域、权利来源和许可有效期；
- 与租户已知高风险案例的精确或高相似匹配。

基础检查可以在任务提交前或生成后自动运行。输入不完整、检测服务不可用或规则版本过旧时返回 `unknown` 或 `stale`，不得降级为低风险。

### 2.2 深度风险检查

深度检查用于准备发布或审核有争议的设计，扩展检查：

- TRO 或诉讼风险名单及其来源时间；
- 艺术家、版权作品和公开权利声明；
- 网络证据与视觉相似候选；
- 设计内部元素、文字、构图和整体外观的分项相似度；
- 品牌许可范围、地域、媒介、期限和是否允许衍生作品。

网络证据必须保存来源 URL、页面标题、采集时间、摘要、证据截图或内容哈希以及检索器版本。外部页面失效后保留历史证据并标为“来源当前不可访问”。

## 3. 风险模型与门禁

### 3.1 风险状态

| 状态 | 含义 | 默认门禁 |
| --- | --- | --- |
| `high` | 存在强匹配、明确权利冲突或许可不覆盖 | 阻断生成、Listing、生产和导出 |
| `medium` | 存在有意义的相似或证据不足以自动判断 | 必须由权利审核人员决定 |
| `low` | 未发现显著风险，但不代表已授权 | 仍需正常设计/Listing 审核 |
| `unknown` | 服务失败、输入不足或无法判断 | 阻断需要风险结论的后续动作 |
| `stale` | 结果超过组织有效期或数据源已更新 | 要求重新检查后再发布或导出 |

风险等级由规则结果、模型结果和权利证明共同形成，但报告必须分别展示各部分，不只输出单一分数。组织可以配置更严格门禁，不能配置高风险自动放行。

### 3.2 人工决定

权利审核人员可以确认阻断、要求补充证据或在中风险下有限放行。有限放行必须记录理由、适用商品/站点/时间范围、审核人和到期时间。高风险不能通过普通人工操作放行；如确有新增许可，必须创建新的权利评估并重新运行检查。

## 4. 风险报告

`RightsAssessment` 报告至少包含：

- 被检查资产版本、任务和业务上下文；
- 风险状态、置信度和非法律意见提示；
- 命中的文字、商标、角色、作品或相似候选；
- 每项证据的来源、时间、类型和可访问状态；
- 视觉相似度、文字相似度和规则命中，彼此分开；
- 数据源版本、规则版本、模型与模型版本；
- 检查时间、有效期和重新检查原因；
- 人工决定、理由和范围。

结果列表默认按高、中、低、未知、过期排序，可以筛选和批量选择。批量丢弃只改变候选的业务状态，不删除报告或原始资产。

## 5. 智能检索

智能检索是本模块支撑全作图中心的公共能力，但不增加一级导航。

### 5.1 创建索引

用户可以从任务原图、任务结果、我的空间、本地上传或结构化批量清单创建租户私有索引。系统保存内容哈希、感知指纹、向量版本、资产域和业务关联。

- “重复过滤”只阻止重复创建索引，不静默删除或阻止资产上传；
- 可选择在建索引前执行基础风险检查；
- `customer_order` 素材默认不得进入长期视觉索引；
- `research` 与业务资产在相同查询中可以对照，但结果必须显著区分资产域。

### 5.2 检索与去重

用户上传查询图或选择现有资产，可调整查询主体并查看精确重复、视觉相似和业务关联。列表前置显示相似度与指纹版本，不把阈值命中描述为“侵权”。

Listing 前检查支持在指定店铺、商品组或租户范围内比较前 N 张轮播图片，N 由组织配置。采集扩展的去重仍只针对研究数据，不把竞品内容写入授权索引。

### 5.3 索引生命周期

删除索引不删除源资产；删除、隔离或失去访问权的源资产必须立即从检索结果隐藏并异步清理索引。重建索引创建新指纹版本，在完成切换前继续服务旧版本，避免检索中断。

## 6. 印花图检索

印花图检索用于在商品发布或订单到达后找回准确的设计来源。用户可按任务编号、商品、SPU、SKU、Listing 版本、外部商品标识或导出清单查询，并下载有权限的原图、提取图、生成图和生产图。

要求：

1. 关联必须来自显式外键与不可变清单，不使用字符串后缀推断 SPU/SKU 关系。
2. 查询多个外部商品标识时逐项返回匹配、未匹配和歧义状态。
3. 同一 SKU 有多个设计版本时默认展示生产或 Listing 清单锁定的版本，不自动选择“最新”。
4. 下载前重新校验租户、资产域、权限和权利状态。

## 7. 外部数据与时效

商标、版权、TRO 和网络证据可能随时间变化。每个数据源配置刷新周期、健康状态和最后成功更新时间。检查任务使用当时锁定的数据源快照；数据源故障时报告明确说明未完成的检查项。

搜索与数据源接入必须遵守站点条款和访问政策，不绕过登录、验证码、反自动化措施或受保护接口。需要账号或付费数据时使用正式集成与租户凭证，不共享凭证。

## 8. 错误处理

| 场景 | 系统行为 |
| --- | --- |
| 某一风险数据源不可用 | 完成其他检查，结果为 `unknown` 或部分完成并列出缺失源 |
| 证据 URL 失效 | 保留历史证据摘要和哈希，标记当前不可访问 |
| 视觉索引尚未完成 | 展示索引进度，不返回伪完整结果 |
| 查询有多个同等匹配 | 返回歧义列表，要求用户选择，不自动绑定 SKU |
| 风险报告过期 | 阻止需要有效报告的后续动作，并提供重新检查入口 |
| 高风险资产尝试导出 | 返回门禁错误，记录安全审计且不生成导出文件 |

## 9. 验收标准

1. 基础和深度检查产生版本化报告，并明确区分规则、网络证据、视觉相似和权利证明。
2. 高风险在任务、Listing、生产和导出接口均被阻断；未知和过期状态不能默认为低风险。
3. 报告显示“辅助判断、非法律意见”，低风险不显示“可放心使用”等保证性文案。
4. 智能检索能够区分精确重复与视觉相似，并显示资产域。
5. 订单顾客图片默认不进入长期视觉索引。
6. 印花图检索可从 SKU 或导出清单准确定位锁定版本，不能因存在更新版本而漂移。
7. 跨租户索引、报告和证据不可见；下载需要重新授权。
8. 数据源部分失败、证据失效、报告过期和歧义匹配均有明确状态与恢复路径。

## 10. 当前工程协议（2026-08-04）

当前已交付 `rights_risk_scan` 的严格异步报告边界。任务固定 1–100 张研究域或授权域栅格素材，并固定基础/深度、Amazon/Etsy 适用范围、是否计算视觉相似度、补充检查词和 1–90 天有效期。处理器必须为每张输入返回一份小型 JSON 报告与一条严格质量记录；批次部分成功、输入遗漏、文件重复、模型漂移或失效时间不符均失败关闭。

每份报告分别记录法律风险 `high/medium/low/unknown`、置信度、规则命中、证据引用、来源可访问状态、检查时间、数据源版本、规则版本、模型与模型版本。视觉相似度只有在任务显式开启时才能出现，并使用独立字段展示，不能写入法律风险分值。页面固定显示“辅助判断，不是法律意见”。

Worker 会从通过校验的质量快照为每个输入资产创建版本化 `RightsAssessment`：

- `high`：任务状态为 `blocked`，源素材权利状态改为 `rejected`，阻断后续生成、Listing 和导出；
- `unknown`：任务状态为 `blocked`，源素材权利状态降为 `unverified`，缺失数据源必须明确列出；
- `medium`：进入人工复核，授权素材在形成新决定前降为 `unverified`；
- `low`：仍进入人工复核，不代表获得授权，也不绕过正常设计和 Listing 审核。

导出接口会重新解析严格快照，并拒绝高风险、未知或已过期报告。当前仓库提供任务、报告、门禁、视觉检索和租户隔离边界，但不内置商标局、TRO、版权库或网络爬取数据；只有管理员接入经审查、遵守来源条款的风险处理器并显式启用后，工具才可用。
