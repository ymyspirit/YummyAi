# POD 模块 PRD 03：图案处理

## 1. 模块目标

提供设计与生产前的确定性或受控 AI 图像处理，包括抠图、超分、扩图、裁剪压缩、矢量化和授权去水印。模块优先保持原始内容，凡改变或推断像素的操作必须在结果元数据中标记。

公共任务、资产域、版本和审核规则遵循[总 PRD](../2026-08-03-yummyai-pod-workbench.md)。

## 2. 工具能力

### 2.1 一键抠图

| 需求编号 | 要求 |
| --- | --- |
| PROC-CUTOUT-01 | 支持人物、商品和动物三类主体模型，前端只展示服务端已启用类别 |
| PROC-CUTOUT-02 | 输出透明背景或指定纯色背景，支持自定义尺寸和自动裁边 |
| PROC-CUTOUT-03 | 结果可以使用点选、保留画笔和删除画笔微调；每次保存创建新版本 |
| PROC-CUTOUT-04 | 质量检查透明边缘、残留背景、主体孔洞和白边/黑边 |

透明结果只允许 PNG 或其他明确支持 alpha 的格式。若用户选择 JPEG，必须先选择背景色并在提交前显示扁平化预览。

### 2.2 超分提质

支持“超分辨率”和“清晰度增强”两种目标，输出档位由能力配置提供，至少能表达 1K、2K、4K 和更高档位。超分记录真实输出像素，而不是只记录营销档位。

系统建议在抠图前进行超分，以减少透明边缘伪影，但允许用户自行选择顺序。人脸、文字、细线和重复纹样分别执行质量检查；生成的新细节属于 AI 推断。

### 2.3 扩图

扩图支持智能补全和纯色延展：

- 智能补全支持常用与自定义比例、输出数量和扩展区域预览；
- 纯色延展支持颜色和扩展倍数，保持原图不缩放；
- 原图边界与扩展范围必须可视化；
- 智能补全部分保存推断蒙版，纯色延展记录所用颜色。

### 2.4 裁剪压缩

| 需求编号 | 能力 |
| --- | --- |
| PROC-COMPRESS-01 | 按目标字节数压缩，显示预计与实际大小；无法达标时返回最低可达大小和原因 |
| PROC-COMPRESS-02 | 将长边或宽高调整到能力配置允许的范围，默认不放大小图 |
| PROC-COMPRESS-03 | 白边裁剪与中心裁剪分开选择，并显示裁剪预览 |
| PROC-COMPRESS-04 | 仅对自有图片支持在左上或右上添加企业水印及偏移 |
| PROC-COMPRESS-05 | 输出 JPEG、PNG 或 WebP；格式转换明确提示透明通道、动画或色彩损失 |

压缩、缩放、裁剪和加水印可以在同一配方中组合，但结果必须记录操作顺序。

### 2.5 转矢量图

转矢量适用于扁平、边界清晰、渐变较少的图案。支持 SVG、EPS 和 PNG 预览。结果质量检查包括：路径是否闭合、孔洞方向、孤立小路径、颜色数量、节点数量和缩放预览。照片或复杂渐变输入必须显示“不适合自动矢量化”警告，不能伪装成精确矢量结果。

### 2.6 授权去水印

去水印只用于企业拥有原图或已获得去除许可的素材，例如清理内部样稿水印。提交前必须选择权利依据和业务理由；研究域、来源不明、版权图库预览或第三方商品图一律阻断。

处理记录包含原图版本、权利评估、操作者、理由、水印区域和结果版本。此能力不提供批量抓取、平台水印绕过或“检测不到来源即可处理”的路径。

## 3. 格式与色彩

工具根据用途声明支持格式，公共集合包括 PNG、JPEG、WebP、TIFF、SVG 和 EPS，但前端不得为所有工具展示全部格式。

- PNG：透明图、无损图和中间结果；
- JPEG：无透明的照片或压缩交付；
- WebP：网络预览和压缩交付；
- TIFF：生产或高位深工作流；
- SVG/EPS：通过矢量质量检查的路径结果。

任何 RGB/CMYK 转换都要记录源配置、目标配置和颜色配置文件。没有可靠转换能力时，不提供选项而不是只修改元数据标签。

## 4. 操作编排

处理结果可以继续进入另一个工具，但每一步都创建独立任务和资产版本。常用建议链路为：

`超分提质 -> 一键抠图 -> 裁剪压缩`

`图案裁剪/印花提取 -> 超分提质 -> 转矢量图`

界面可以提供快捷入口，但不能把多步操作压成不可追溯的单个结果。若未来支持复合配方，仍需记录每个阶段的输入、输出和失败状态。

## 5. 错误处理

| 场景 | 系统行为 |
| --- | --- |
| 透明图转 JPEG | 要求选择背景色并确认扁平化 |
| 目标文件大小不可达 | 返回实际最低大小、质量和建议尺寸，不反复无界重试 |
| 超分输出出现明显伪影 | 质量检查失败，允许查看但不能自动批准 |
| 矢量路径过于复杂 | 标记需要人工清理，提供 PNG 预览但不标记生产可用 |
| CMYK 配置缺失 | 阻止 CMYK 输出并提示管理员配置 |
| 去水印权利不足 | 在创建模型任务前阻断并记录安全审计 |

## 6. 验收标准

1. 人物、商品和动物抠图均可输出透明结果并进行边缘微调。
2. 超分结果记录真实像素和 AI 推断状态；文字与细线样例有质量警告测试。
3. 智能扩图与纯色延展均正确保存原图边界和扩展区域。
4. 裁剪压缩能组合尺寸、裁剪、格式、压缩和企业水印，并记录操作顺序。
5. SVG/EPS 输出通过路径闭合、孔洞、节点和缩放检查；不适合输入会被明确提示。
6. 未经授权的去水印请求在前端和 API 均被阻断，审计日志不记录文件内容。
7. 跨工具继续处理形成清晰的版本关系，任何步骤失败不覆盖上一版本。

## 7. 当前工程协议（2026-08-04）

当前已交付六个工具的通用异步任务、严格参数快照、逐输入结果映射、人工审核证据和导出再校验。每次任务固定 1–100 张授权域栅格素材，每张输入必须且只能返回一张完整结果；部分成功、额外文件、重复序号、格式或技术元数据漂移均失败关闭。

| 工具 | 当前固定参数与结果约束 |
| --- | --- |
| 一键抠图 | 边缘细化、保留阴影；固定透明 PNG，保持源图尺寸，不允许生成像素 |
| 超分提质 | 2×/4×、72–1200 DPI、降噪、锐化、PNG/JPEG/WebP/TIFF；真实输出宽高必须等于源图倍数，全图新增细节标记为 AI 增强 |
| 扩图 | 1:1/4:5/3:4/16:9、四周/横向/纵向、可选说明、PNG/JPEG；目标比例和全部 AI 延展矩形必须一致 |
| 裁剪压缩 | 像素宽高、质量、DPI、RGB/CMYK、PNG/JPEG/WebP/TIFF、透明通道；JPEG 与透明通道冲突在创建前阻断 |
| 转矢量图 | SVG/EPS、颜色数量、平滑、路径闭合、RGB/专色；逐文件记录路径数，并拒绝脚本、外部引用、DOCTYPE、ENTITY 和不安全 SVG |
| 授权去水印 | 权利确认、区域说明、PNG/JPEG；修复矩形作为 AI 推断区域保存，研究域和权利未批准素材不能进入任务 |

当前协议是可接处理器的安全执行边界，不代表仓库内置了第三方抠图、超分、扩图、压缩或矢量算法。主体类型选择、画笔微调、纯色智能延展、目标字节压缩、复合操作配方与生产级色彩配置仍按本 PRD 后续实现；在完成之前不在界面伪装为可用参数。
