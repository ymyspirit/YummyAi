# POD 模块 PRD 07：生产图

## 1. 模块目标

把已批准的印花、来图定制结果和生产模板转换为供应商可使用的裁片、位图、分层或矢量生产文件，并用不可变 `ProductionManifest` 锁定输入、模板、参数、文件和审核状态。

本模块生成内部生产文件和导出包，不模拟供应商或平台后台操作。公共任务、资产域、版本和审核规则遵循[总 PRD](../2026-08-03-yummyai-pod-workbench.md)。

### 1.1 当前实现切片（2026-08-04）

- 已提供订单上下文 `fulfillment_composite` 的专用异步执行边界：输入来自成功的订单个性化准备项目，输出限定为 PNG/TIFF，并固定格式、DPI、色彩模式、透明通道、模型来源和质量检查。
- 生产图模块已接入订单履约操作台，可选择安全订单候选、查看预处理批次和逐行失败、对成功项目配置格式/适配/DPI/色彩/透明通道/AI 提质并创建 `fulfillment_composite`。未配置专用订单处理器时按钮禁用并显示明确边界。
- 队列只携带渲染任务 ID。Worker 临时解密订单槽位、复核顾客文件不可变证据，只向明确授权的专用处理器发送最少必要内容；结果写回 `order` 资产域并创建待权利确认、待设计审核的新版本。
- 该执行结果不是 `ProductionManifest`。必须先完成 `customer_provided` 权利确认和设计审核，再使用现有生产清单 API 固定生产尺寸、输出证据和质量检查；任何一步都不能自动批准。
- `piece_compose` 已有严格裁片排版契约：固定输入顺序与稳定裁片键、生产画布、定位模板、适配方式、自动/手动排版、最低 DPI、间距和旋转策略。Worker 对每个输出核对逐裁片位置、方向、缩放、有效 DPI、缝线、越界、重叠、空白和文件证据，失败结果终止且不能进入审核。
- `piece_extract` 已有严格裁片提取契约：每个任务只固定一份授权源图或模板，明确分版/合版、透明通道/深色裁片线、稳定裁片键、名称、方向、翻转、缝份、输出格式、置信度阈值与模板草稿名称。Worker 重新核对区域集合、边界闭合、画布范围、逐片文件、完整画布、模板 ZIP 与低置信度人工确认标记。
- `uv_layers` 已有严格通道契约：只固定一份授权源图，明确稳定图层键、名称、通道、顺序、透明度、供应商通道配置和生产画布。Worker 逐层核对来源像素、统一坐标、透明文件、合成预览和 ZIP；未解决冲突必须给出机器可读区域，并在导出接口再次阻断。
- `vector_fulfillment` 已接入同一订单履约操作台与专用异步边界：只读取批准的 SVG 模板源和加密订单槽位快照，固定物理画布、模板配置、文字转路径、镂空、连接桥、最小线宽、专色/CMYK 与路径修复策略。Worker 拒绝不安全 SVG、生成式推断、嵌入位图、部分成功和不完整质量证据；API 创建 SVG 生产清单时再次读取权威任务快照并验证设计版本文件归属。
- 仓库不内置供应商像素引擎、PSD 效果渲染、自动排版算法、UV 通道或 SVG 路径执行器。裁片、UV 与矢量执行通过受控处理器完成并由本仓库失败关闭校验；算法本身仍取决于部署和独立验收。

## 2. 生产模板

### 2.1 定位模板

用户可以创建空白定位模板、导入 PNG/SVG，或复制组织模板。模板至少定义：

- 商品、SKU、物理尺寸和单位；
- 完整画布尺寸、像素尺寸、DPI 和色彩模式；
- 裁片/印刷区域名称、路径、位置、尺寸、旋转和层级；
- 缝纫指导线的内缩距离、颜色和单位；
- 印花填充策略：适应、充满或拉伸；
- 背景填充、出血、安全区和供应商要求；
- 输出格式和文件命名规则。

多印花模板依靠稳定区域键匹配，不依赖用户可见名称的模糊比较。生产模板版本与 SKU 显式绑定，已生成生产清单的模板不可修改。

### 2.2 模板编辑

编辑器支持添加、重命名、排序、缩放、翻转和旋转区域，提供实际尺寸标尺和缩放预览。几何路径越界、重叠、缺失闭合或低于最小尺寸时显示诊断。所有人工修复保存为新模板版本。

## 3. 裁片图提取

### 3.1 分版模式

分版模式使用透明 PNG 裁片或可识别的独立区域：

- 自动识别裁片边界并保持原始形状；
- 支持翻转和 90 度旋转的裁片；
- 用户可在编辑器修正区域和名称；
- 输出完整画布、独立裁片和区域元数据；
- 精度高于合版模式，作为推荐生产方式。

### 3.2 合版模式

合版模式接受白底 JPG/PNG 与清晰黑色裁片线，适用于已按正面方向排好的快速模板。系统按边界切分但不自动推断复杂翻转；低置信度区域必须人工确认。

### 3.3 需求

| 需求编号 | 要求 |
| --- | --- |
| PROD-PIECE-EXTRACT-01 | 分版/合版选择在提交前说明精度、输入要求和限制 |
| PROD-PIECE-EXTRACT-02 | 每个裁片具有稳定区域键、名称、路径、方向和物理尺寸 |
| PROD-PIECE-EXTRACT-03 | 提取结果可保存为定位模板草稿，必须经人工确认后变为可生产 |
| PROD-PIECE-EXTRACT-04 | 输出支持 RGB/CMYK 和 PNG/TIFF/JPEG 的有效组合，实际集合由能力配置提供 |

当前创建协议每行裁片定义使用 `stable-key|名称|角度|翻转`；角度只允许 0/90/180/270，翻转只允许 `none/horizontal/vertical/both`。分版固定使用透明边界和透明 PNG/TIFF，合版固定使用深色裁片线，只有不保留透明通道时可以选择 JPEG。任务只接受一份固定源素材，避免多图之间的区域来源歧义。

处理器必须返回完整画布、每个裁片的独立生产文件和一个定位模板 ZIP 草稿。质量快照逐裁片记录源坐标、物理尺寸、方向、翻转、闭合边界、印刷区域、缝线、置信度和对应文件；顶层记录空白、重复、意外及低置信度裁片键。Worker 使用请求阈值重新计算低置信度集合，缺失的人工确认标记、越界区域、文件映射不全、格式/透明度/DPI/色彩不一致均终止任务。模板始终保持 `awaiting_confirmation`，不会因模型识别结果自动变为可生产版本。

## 4. 裁片图合成

用户选择商品/SKU、定位模板版本和一个或多个已批准印花版本。系统按区域键将印花以适应、充满或拉伸方式放置，并生成：

1. 完整生产画布；
2. 裁片边界与印刷区域预览；
3. 独立裁片文件（模板需要时）；
4. 生产参数与质量检查报告。

拉伸模式必须显著提示可能变形；默认使用适应或模板指定策略。印花空白、超出安全区、DPI 不足和颜色模式不匹配均进入质量诊断。

当前 `piece_compose` 请求要求每份固定输入按顺序对应一个唯一裁片键。自动排版不能夹带手动位置；手动排版必须为每个裁片提供且只提供一条 `pieceKey,x,y,rotation,scale` 记录。Worker 只接受 production 角色的 PNG、TIFF 或 ZIP，位图必须声明与请求一致的单位、色彩模式和不低于阈值的 DPI，排版不能引入生成式像素推断。

处理器的质量快照必须逐裁片返回 `inputOrdinal`、坐标、尺寸、单位、0/90/180/270 度方向、X/Y 缩放、有效 DPI、印刷区域内和缝线保留证据；顶层必须明确无重叠、无越界、无空白、尺寸/色彩/最低 DPI 通过。逐文件检查必须覆盖全部输出文件并共同覆盖全部固定裁片键。页面只展示经过严格模式解析后的安全证据，不显示处理器自由字段。

## 5. 履约图合成

### 5.1 手动合成

履约人员选择模板并通过表格填入图片、文字、颜色、背景和元素。支持快速、横向和纵向上传，规则复用来图定制模块。提交前显示每行预览、模板版本、SKU、DPI、色彩和输出格式。

### 5.2 Amazon/Etsy 订单合成

系统从经过扫描和映射的订单定制版本读取输入，根据 `SkuTemplateBinding` 选择模板。首次外部 SKU 映射必须人工确认，之后只在模板版本、商品或尺寸一致时自动匹配。

自动构图可以关闭以还原顾客排序，或选择全局均衡/主体聚焦；自动补齐和自适应提质必须记录 AI 推断。订单数据只在订单 PII 域处理，生产文件对供应商暴露最少必要信息。

用户上传的第三方文件包可以使用受控解析器，但当前不自动登录或抓取 TEMU 等非 Amazon/Etsy 平台，也不回写状态。

当前订单履约合成由 `POST /v1/pod/order-personalization-render-tasks` 创建，必须引用已成功准备的批次项目。它只生成待审核的订单私有设计结果，不直接创建供应商下载包；人工完成权利与设计审核后，才可显式创建不可变 `ProductionManifest`。

作图中心的生产图操作台复用来图定制的安全候选和预处理批次，可在 `fulfillment_composite` 的 PNG/TIFF 与 `vector_fulfillment` 的 SVG 之间选择。页面显示排队、渲染、部分成功、失败和待审核状态；结果版本可跳转到设计审核。顾客文字、留言、图片引用和加密槽位解析不进入页面数据或表单参数。

## 6. UV 智能分层

UV 分层将批准的图片拆分为透明图层或生产通道。创建任务时选择分层模式、物理尺寸和 DPI。结果页展示各层缩略图、顺序、通道、透明度和合成预览。

要求：

- 原图和全部分层结果使用同一画布与坐标系；
- 每层记录来源像素、用途和模型/算法版本；
- 支持在编辑器调整层顺序、可见性、透明度和有限的遮罩修复；
- 调整后创建新分层版本；
- 导出前验证层数、尺寸、透明通道、命名和供应商通道规则。

自动分层无法判断的区域标为冲突区域，必须人工处理，不能静默分配到任意层。

当前请求每行图层定义使用 `stable-key|名称|通道|顺序|透明度`，通道限定为 `color/white_ink/varnish/emboss/cut/mask`，键和顺序必须唯一，白墨/光油开关必须与定义一致。任务只接受一份固定源素材，所有图层、合成预览必须保持相同物理画布、DPI、色彩模式和透明通道，输出限定为透明 PNG/TIFF 加 ZIP 图层包，不能通过改扩展名伪造通道文件。

质量快照逐层记录通道、顺序、透明度、来源像素、冲突像素和文件名；每个冲突区域记录坐标、原因、候选图层与置信度。Worker 重新核对区域范围、候选键、逐层文件、合成预览、ZIP 以及全部输出覆盖。存在冲突时 `passed=false`、`exportReady=false`、`manualReviewRequired=true`，页面显示“禁止导出”；即使设计版本被人工审核，导出服务仍会拒绝该质量快照。人工修复必须创建冲突为零的新任务/版本，不能覆盖原结果。

## 7. 履约矢量合成

### 7.1 适用场景

面向金属激光切割、雕刻和其他需要标准化 SVG 的生产。输入为已批准 SVG 模板和订单/批量替换数据。

### 7.2 模板能力

- 可替换文字、字体、间距、变形、弧形和曲线排版；
- 可选文字镂空或实体；
- 内孔、外环和指定路径按模板规则缩放；
- 连接桥检查，防止镂空部件脱落；
- 路径编辑与画笔修复；
- 人工批量替换或订单文件解析合成。

字体在进入生产前必须转换为路径或与供应商明确约定。系统不得使用未授权字体，也不得只修改扩展名把位图伪装为 SVG。

### 7.3 矢量质量检查

检查路径闭合、自交、重复路径、孤立节点、孔洞方向、最小线宽、最小桥宽、画布越界、单位和缩放。失败结果可以预览和人工修复，但不能标记为生产可用。

当前创建协议固定使用 SVG、透明背景和模板适配，关闭生成式增强，要求 CMYK 或专色，并明确模板配置、物理宽高/单位、模板/自动排版、文字转路径、镂空、桥宽、最小线宽和安全修复策略。处理器输出必须是 production SVG，且不得包含脚本、外部资源、DOCTYPE/ENTITY、嵌入位图或生成式推断。质量快照逐文件列出全部输入稳定键、画布、viewBox、路径数、最小线宽和最小桥宽，并在顶层证明字体授权、文字转路径、闭合、自交、重复、孤立节点、孔洞、边界和修复结果。任何不一致使用稳定 `VECTOR_*` 诊断失败关闭；失败任务不能通过人工审批直接变为可生产，必须修复输入或模板后创建新版本。

## 8. ProductionManifest

每次批准的生产输出生成不可变清单，至少包含：

- 租户、订单/订单行或设计任务引用；
- 商品、SKU、供应商和工艺；
- 订单定制版本或设计版本；
- 生产模板与配方版本；
- 所有输入资产版本和权利状态；
- 输出文件名、对象键、SHA-256、字节数、格式、尺寸、DPI、色彩模式和通道；
- 质量检查结果、人工调整、审核人和审核时间；
- 生成器、算法或模型版本；
- 清单版本和创建时间。

下载生产包时再次验证清单、权限、资产状态和校验和。文件变化必须生成新文件与新清单，不修改原清单。

## 9. 生产检查与调整

结果页同时显示顾客/设计预览、生产结果、尺寸、DPI、格式和执行步骤。允许的调整必须通过编辑器创建新版本。批量页面支持筛选失败原因和显式选择下载；“下载全部”只包含当前有权下载且已批准的文件。

质量状态为：

`pending -> passed / warning / failed -> overridden`

`overridden` 只允许具备生产审核权限的人员使用，并记录结构化原因；路径未闭合、恶意文件、资产权利阻断等安全失败不能覆盖。

## 10. 错误处理

| 场景 | 系统行为 |
| --- | --- |
| SKU 无模板 | 订单/任务进入待配置，不自动选择近似尺寸 |
| 裁片边界不闭合 | 阻止可生产状态，允许编辑后创建新模板版本 |
| 印花 DPI 不足 | 提示自适应提质或更换素材；提质结果需重新审核 |
| RGB/CMYK 转换不可用 | 阻止目标色彩输出，不只修改文件标签 |
| UV 层冲突 | 标记冲突区域并要求人工调整 |
| SVG 连接桥不足 | 阻止生产可用状态，显示最小桥宽与位置 |
| 文件校验和不一致 | 隔离文件、阻止下载并记录安全事件 |
| 批量单项失败 | 保留其他生产文件，失败项可单独调整和重试 |

## 11. 验收标准

1. 分版和合版裁片提取均形成稳定区域键、模板草稿和质量诊断。
2. 裁片合成支持适应、充满和拉伸，并对变形、越界、空白和 DPI 不足给出检查结果。
3. 手动与 Amazon/Etsy 订单合成都锁定 SKU、模板和订单定制版本，PII 不进入普通日志。
4. UV 分层保持统一画布与坐标，冲突区域必须人工处理，调整形成新版本。
5. 履约 SVG 通过路径、孔洞、桥宽、线宽、单位和缩放检查。
6. 每个批准输出生成完整、不可变且可验证校验和的 `ProductionManifest`。
7. 未批准、权利阻断、质量失败或无权限文件不能进入批量下载。
8. 修改任何输入、模板、参数或生产文件都会生成新清单，历史生产包保持可追溯。
9. 订单履约渲染只向专用处理器传递最少必要 PII，输出位于订单私有域，且在双重审核前不能生成生产清单或下载包。
