# POD 模块 PRD 05：套图&标题

## 1. 模块目标

将已批准的商品图、印花图和产品信息转换为 Listing 候选素材，包括商品套图、标题草稿、模特试衣、商品图裂变、一键套图、换背景和短视频。结果是 YummyAI 内部候选资产，不伪装成平台在线效果；只有经审核并绑定具体 Listing 版本后才能进入导出或发布流程。

公共任务、资产域、版本和审核规则遵循[总 PRD](../2026-08-03-yummyai-pod-workbench.md)。

### 1.1 已实现的严格执行协议

`product_suite`、`title_draft`、`virtual_try_on` 与 `background_replace` 已进入统一异步任务、Worker 校验、任务证据和不可变导出路径；商品图裂变复用印花设计的严格创意协议，商品短视频使用本模块第 7.2 节协议。四个工具在创建时固定平台、站点、输出数量和专项参数，输出逐项固定全部来源序号、文件或标题内容、商品身份、已确认事实、内容安全、文字复核、AI 来源、模特许可或仅背景变化证据。

商品套图允许单个槽位隔离失败：成功项、失败索引、稳定错误码和请求总数必须完全对账，任务进入“部分成功”，不会用空白或重复文件补齐。其他三类工具不接受部分结果。标题输出为小型 UTF-8 文本文件，Worker 重算内容 SHA-256、字符数和字节数；模特试衣必须逐文件确认模特许可；换背景必须以局部 AI 区域标记背景并证明主体未改变。所有结果仍只是 Listing 候选，必须完成人工设计和权利审核后才可绑定固定 Listing 版本槽位。

## 2. 商品套图与一键套图

### 2.1 入口

用户从作图中心、商品、SKU 或 Listing 版本发起套图任务。必须先选择商品、至少一个已授权设计版本和目标平台/站点；未选择 Listing 时可以生成通用候选，但不能自动填充平台槽位。

### 2.2 服装套图

服装能力配置至少支持以下图片类型：

| 类型 | 默认数量 | 单次上限 | 要求 |
| --- | ---: | ---: | --- |
| 模特图 | 2 | 4 | 可选择模特，保持服装版型、颜色和印花位置 |
| 平铺图 | 2 | 4 | 展示正反面或关键细节，不虚构不可见结构 |
| 卖点图 | 2 | 4 | 只使用已确认卖点和规格，不编造数值 |
| 社交场景图 | 1 | 2 | 场景与目标人群匹配，标记 AI 场景 |
| 白底图 | 1 | 2 | 符合目标平台背景与主体占比规则 |

### 2.3 手机壳套图

手机壳至少支持社交图、场景图和白底图。默认/上限由服务端配置，初始参考为社交图 4/6、场景图 2/4、白底图 1/2。所有图必须保持设备型号、镜头孔位、边框、材质和印花方向一致。

### 2.4 结果操作

套图结果按类型分组，可逐张保留、退回、替换或关联 Listing 图片槽位。整套结果可保存为套图模板，但模板只保存构图、槽位、提示和规则，不把顾客或研究域图片固化为可复用素材。

## 3. 标题提取与标题草稿

标题功能从批准的商品数据、设计内容、目标平台、站点、语言和关键词方向生成标题草稿。图片识别只能提出可复核的主题、颜色和元素建议，不能从竞品图片复制或近似改写其标题。

每个标题草稿必须记录：输入商品版本、图片版本、平台规则版本、关键词来源、模型、提示模板、字符/字节计数和风险检查。用户编辑标题创建新 Listing 草稿版本；标题永远不能绕过主 PRD 的 Listing 字段审核。

错误或不确定的图像识别属性以候选标签展示，不直接写入标题。商标、品牌、角色和艺术家名称进入风险检查。

## 4. 模特试衣

### 4.1 输入与参数

- 优先上传服装正面和背面；缺少背面时不得虚构准确背部细节；
- 选择平台提供且有合法授权的模特，支持不同年龄段、体型和肤色；
- 选择背景、姿势、视角、比例和输出数量；
- 结果需保存服装输入版本、模特资产许可、姿势和模型版本。

### 4.2 保真要求

保持服装版型、领口、袖型、长度、颜色、纹理和印花。质量检查比较原商品与结果的轮廓、印花位置、文字、手指/肢体和遮挡。结果不能表述为真实拍摄；Listing 使用时遵循平台对 AI 图像的披露规则。

## 5. 商品图裂变

商品图裂变只改变用户明确选择的维度：印花、背景、视角或场景。默认“商品与背景不变，仅替换印花”；系统检测商品结构漂移、颜色变化、品牌标识变化和印花错位。

输入必须是自有/授权商品资产。研究域商品图只能用于研究差距分析，不能提交裂变。结果可以保存为新的商品图候选，但需设计审核后关联 Listing。

## 6. 换背景

支持背景变体库、自定义提示词和背景参考图。参考强度使用低、中、高标签，默认高，实际数值保存在配方中。背景库按品类和场景维护，并记录每个模板的权利来源。

结果质量检查：主体轮廓、接触阴影、透视、光照方向、反射、遮挡和印花保持。用户可从结果继续执行裁剪压缩、套图或视频任务。保存背景模板时不包含商品主体。

## 7. 商品图片与短视频

### 7.1 图片生成

商品图片生成复用套图、换背景和商品图裂变能力，不单独建立资产类型。任何卖点文字必须来自商品已确认字段；无法取得的数据展示缺失，不由模型补造。

### 7.2 视频生成（POD-3）

视频支持模特动作、商品运动和风铃展示三类模式：

- 模特动作：使用已批准的试衣结果或商品图，选择动作预设或自定义提示；
- 商品运动：支持宠物用品、地毯、毯子、手机壳、桌布等品类预设；
- 风铃展示：支持产品形状、背景和氛围组合，保持挂件数量、图案和结构。

当前可执行切片固定输入 1–20 张权利已批准的授权域商品图片，时长 5–60 秒，镜头模板为商品聚焦、生活方式或细节展示，画幅支持 1:1、4:5、9:16、16:9，输出支持 720p/1080p 与 24/25/30 FPS。转场、循环、字幕和音轨必须在创建任务时固定；自定义字幕不能为空，许可音轨必须同时固定许可引用和权利确认。安全区检查始终开启，AI 商品运动必须由用户显式允许并保留证据。

处理器只允许返回一份 H.264 MP4。Worker 重新验证 MP4 容器、时长、帧率、尺寸、RGB 非透明输出、AAC/无音轨、全部输入序号覆盖、空白/损坏帧、字幕溢出、音频削波、许可引用与 AI 运动证据。任何部分成功、额外输出、输入遗漏或技术元数据漂移都会失败关闭；通过后仍只创建待审核设计版本，未审核结果不能下载或进入 Listing/发布清单。

## 8. Listing 关联

1. 结果关联具体 Listing 版本和图片/视频槽位，不关联“最新 Listing”。
2. 同一资产可以作为多个 Listing 候选，但每个关联保留平台、站点、槽位和审核状态。
3. Listing 版本锁定后更换图片会创建新 Listing 版本并重新校验。
4. 生成资产未经设计与权利审核时只能处于候选状态，不能进入发布或导出清单。
5. 平台预览必须标明为内部规则预览，不伪装成真实卖家后台或已发布页面。

## 9. 错误与部分状态

| 场景 | 系统行为 |
| --- | --- |
| 商品背面缺失 | 允许生成正面相关素材，背面槽位显示缺失，不虚构 |
| 套图某一类型失败 | 整套进入部分成功，其他类型可继续审核 |
| 商品结构漂移 | 质量检查失败，结果可查看但不能自动批准 |
| 标题使用未确认属性 | 标记字段来源缺失并阻止提交 Listing 审核 |
| 模特许可不可用 | 阻止生成并要求重新选择模特 |
| 视频生成中断或证据不完整 | 本次任务失败并保留诊断；重试创建新版本，不把部分 MP4 提交审核 |

## 10. 验收标准

1. 服装和手机壳套图按类型、默认数和上限生成，切换能力配置后前端同步更新。
2. 标题草稿可追溯到商品、图片、规则和关键词来源，未确认属性不会自动进入标题。
3. 模特试衣结果检查服装结构、颜色、印花、肢体和遮挡，并保留模特许可。
4. 商品图裂变无法使用研究域商品图，且能检测非目标区域漂移。
5. 换背景支持预设、提示和参考图，结果可继续套图或视频且版本关系完整。
6. 套图可逐项审核并绑定具体 Listing 槽位，部分失败不丢失成功结果。
7. 视频只接受 1–20 张授权图片并生成一份 H.264 MP4；全部输入、播放、尺寸、字幕安全区、音轨许可和 AI 运动证据完整后才可进入人工审核，未审核视频不能下载或进入发布清单。
8. 所有平台预览均明确为内部预览，不执行浏览器自动发布。
9. 标题文件内容、SHA-256、字符数、UTF-8 字节数、事实来源、规则版本与人工文字复核证据完全一致；任一漂移失败关闭。
10. 商品套图逐槽位部分成功可追溯；模特试衣缺少许可或换背景缺少主体保持/AI 区域证据时不能进入审核或导出。
