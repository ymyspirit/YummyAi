## 2. 产品定位

POD 作图中心用于把已获授权的设计素材、企业自有素材和顾客定制素材转换为可审阅、可追溯、可复用的设计与生产资产。它不是独立图片站，也不建立平行的商品、订单或文件体系；所有任务、结果、模板和生产文件都要回到现有产品、SKU、Listing、订单、设计版本和导出清单中。

统一业务链路为：

`选择工具 -> 选择有权使用的输入 -> 配置参数 -> 创建异步任务 -> 检查结果 -> 人工审核 -> 保存为新版本 -> 继续加工 / 关联 Listing / 生成生产文件 / 导出`

### 2.1 目标

1. 以统一入口覆盖印花提取、设计、处理、风险检查、商品素材、来图定制和生产图。
2. 将每一次输入、参数、模型调用、人工调整和输出纳入不可变版本链。
3. 将竞品证据、自有/授权资产、AI 生成资产和顾客订单素材隔离管理。
4. 让生成结果可以安全地进入 Listing 审核、订单个性化和生产文件流程。
5. 通过共享任务、模板、检索和审核能力减少七个模块的重复实现。

### 2.2 非目标

1. 不复制教程产品的品牌、积分、折扣、夜间计费或视觉界面。
2. 不提供规避版权、商标、TRO、平台政策或水印权利限制的能力。
3. 不把相似度检查表述为法律意见或“不侵权保证”。
4. 不允许竞品图片直接转为可发布或可生产资产。
5. 不通过浏览器自动化模拟卖家后台发布、下载订单或回写状态。
6. POD-1 不包含市场平台发布；发布继续使用主 PRD 定义的官方授权 API 边界。

## 4. 用户与权限

| 角色 | 默认能力 |
| --- | --- |
| 设计师 | 创建任务、编辑参数、查看输入、上传授权资产、提交结果审核 |
| 商品/Listing 运营 | 从产品或 Listing 创建任务、选择已批准结果、编排图片槽位、生成标题草稿 |
| 审核人员 | 审核权利来源、设计结果、风险报告和生产文件；阻断或退回 |
| 履约人员 | 处理有权访问的订单定制素材、选择模板、检查并下载生产文件 |
| 组织管理员 | 配置工具、模型、容量、保留期、风险门禁和角色权限，不自动获得订单 PII 查看权 |
| 只读访客 | 查看已授权范围内的任务与报告，不可创建、修改、审批或下载敏感文件 |

权限至少拆分为 `pod.task.create`、`pod.task.review`、`pod.asset.download`、`pod.rights.review`、`pod.template.manage`、`pod.order-pii.read`、`pod.production.export`。所有租户数据访问继续通过认证成员关系和 `withTenant()`，调用者不得用请求头选择任意租户。

## 5. 公共任务体验

### 5.1 工具目录

每个工具由服务端能力配置描述，至少返回：工具键、模块、可用状态、交付阶段、输入类型、单次输入上限、像素/字节上限、可选比例、输出格式、输出数量、支持模型、是否需要权利预检以及是否允许订单 PII。

前端不硬编码教程中的“1000 张”“2000 张”等上限；能力配置是唯一显示与校验来源。管理员可以降低租户配额，但不能扩大提供商或安全策略允许的上限。

### 5.2 新建任务

1. 用户从工具卡、商品、SKU、Listing、设计版本、订单行或已有结果发起任务。
2. 输入可以来自本地上传或“我的空间”。上传先创建隔离资产并完成格式、恶意文件、内容域和权利来源检查。
3. 用户配置工具参数、任务备注和结果标签；批量任务必须预览输入数量、预计输出数量和可能成本。
4. 提交使用幂等键。同一用户重复提交相同幂等键只创建一个任务。
5. 创建后立即返回任务编号，实际处理由队列执行，页面显示排队、运行步骤和已完成数量。

### 5.3 任务状态

任务主状态固定为：

`draft -> queued -> running -> succeeded / partially_succeeded / failed / cancelled`

结果审核状态独立为：

`not_submitted -> pending_review -> approved / rejected / superseded`

部分成功必须保留成功结果和逐项失败原因，不得因单张失败丢弃整批。重试从明确的失败项或整个任务创建新运行记录，不覆盖原运行。

### 5.4 结果页

结果页同时展示原图、结果、参数摘要、生成来源、模型、耗时、质量检查、风险状态、版本关系和后续操作。后续操作只显示当前结果真实支持的能力，包括：

- 保存到我的空间；
- 设为设计版本文件；
- 继续改图或发起另一个工具任务；
- 关联商品、SKU 或 Listing 图片槽位；
- 创建来图定制模板或套图模板；
- 提交审核；
- 在批准后生成不可变导出包或生产清单。

## 6. 资产、版本与数据接口

### 6.1 资产域

| 资产域 | 用途 | 允许的下游 |
| --- | --- | --- |
| `research` | 竞品和公开市场证据 | 研究、相似度和风险对照；禁止生成、Listing 和生产导出 |
| `authorized` | 企业自有、许可、委托或已批准素材 | 设计、Listing、模板、生产和导出 |
| `generated` | 从合格输入生成的结果 | 继承输入限制；经审核后可进入授权业务流程 |
| `customer_order` | 顾客为具体订单提供的文字、图片和留言 | 仅对应订单的校样与履约；禁止复用到其他商品或模型训练 |

资产域使用独立对象前缀和读取策略。任何跨域使用都必须通过显式业务动作和门禁；`research` 不能升级为 `authorized`，只能由用户重新上传独立的权利证明和原始授权文件创建新资产。

### 6.2 复用现有模型

作图中心扩展而不替换现有 `DesignTask / DesignVersion / DesignAsset / AssetVersion / Review / ExportJob`。后续实现需要补充以下公共概念：

| 类型 | 目的 | 关键字段 |
| --- | --- | --- |
| `DesignRecipeVersion` | 保存一次可复现的工具配置 | `toolKey`、参数、模型策略、提示词模板版本、创建人、版本号 |
| `ArtifactRelation` | 描述输入、输出和后续派生关系 | `fromAssetVersionId`、`toAssetVersionId`、关系类型、任务运行 |
| `RightsAssessment` | 记录权利来源与风险门禁 | 权利来源、证明引用、有效期、适用范围、风险状态、审核人 |
| `VisualFingerprint` | 支持去重、相似检索和印花反查 | 内容哈希、感知哈希/向量版本、索引状态、来源资产版本 |
| `PersonalizationTemplateSourceInspection` | 固定 PNG/PSD 导入解析与人工确认前证据 | 源资产版本与校验和、解析器版本、状态、画布、槽位建议、警告、诊断 |
| `PersonalizationTemplateVersion` | 不可变的来图定制模板版本 | 画布、PSD/PNG 来源、槽位、字体、效果、预览、状态 |
| `TemplateSlot` | 图片、文字、元素或背景替换位 | 稳定键、类型、几何、填充、校验、是否可替换、复用标签 |
| `SkuTemplateBinding` | 商品规格与模板版本映射 | 商品、SKU、尺寸、模板版本、生效区间、映射状态 |
| `ProductionManifest` | 锁定一次生产输出 | 订单/设计来源、模板版本、输入版本、文件校验和、尺寸、色彩、审核 |

### 6.3 公共创建接口语义

未来公共创建请求至少包含：

```text
toolKey
sourceAssetVersionIds[]
recipeVersionId 或 parameters
businessContext（productId / skuId / listingVersionId / orderLineId，按工具可选）
outputCount
note
resultTags[]
idempotencyKey
```

订单 PII 不得直接放进普通任务参数或日志；接口只接收受控的订单定制版本引用，并在授权域内解析。

### 6.4 结果元数据

每个结果至少记录：文件格式、字节数、像素尺寸、DPI、色彩模式、透明通道、内容校验和、输入版本、配方版本、模型与模型版本、随机种子或不可复现原因、生成时间、AI 推断标记、质量检查结果和风险状态。

AI 修补、扩图、遮挡补全和重绘必须保存机器可读的推断范围；无法生成精确蒙版时，至少记录“整图包含 AI 推断”并在 UI 和导出说明中展示。

## 7. 公共检索能力

### 7.1 智能检索

用户可以从任务原图、任务结果、我的空间、本地上传或批量清单创建租户私有视觉索引。精确重复和视觉相似是两个结果维度；删除索引不等于删除资产，删除资产则必须使其索引不可检索。

检索可以调整查询主体，结果展示相似度、索引来源、资产域、商品/任务关联和可执行动作。相似度不得自动转换为侵权结论。

### 7.2 印花图检索

系统通过不可变关联链按图片、任务编号、产品、SPU、SKU、Listing 版本和导出清单反查原图、提取图、生成图和生产图。不得依赖把 SPU 或 SKU 后缀拼接成外部平台 ID；所有关系使用显式标识和版本外键。

## 8. 权利、安全与审核门禁

1. 上传或选择输入时显示资产域和权利状态；未确认来源的文件不能进入生成任务。
2. 品牌、角色、艺术家、名人或明显商业标识输入必须具备可验证许可范围。
3. “去水印”只允许处理企业自有或已获许可原件，并记录理由、操作者和前后版本。
4. 顾客订单图片需恶意文件扫描，存储在订单 PII 域，签名读取必须同时校验租户、订单和操作权限。
5. 高风险报告阻断生成、Listing 和导出；中风险必须由权利审核人员决定；低风险仍保留提示和证据。
6. 已批准结果发生像素、文字、参数、模板或输入变化后创建新版本并重新审核。
7. 模型提供商不能收到竞品原始文件、订单 PII 或机密提示词，除非有明确的供应商策略、必要性和用户授权；默认不用于训练。
8. 下载、审核、风险放行、权利变更、模板绑定和生产导出进入审计日志。

## 9. 非功能需求

### 9.1 性能与容量

1. 工具目录、任务列表和结果元数据请求 P95 小于 2 秒。
2. 文件上传支持可恢复上传；批量任务逐项显示进度。
3. 图片、向量、PSD 和视频处理均异步执行，不占用 API 请求进程。
4. 大批量任务必须分片、限流并支持取消后停止创建新的子任务。
5. 视觉索引按租户分区；索引重建不影响已批准资产访问。

### 9.2 可用性

每个页面必须提供空、加载、部分成功、失败、无权限、待审核、已阻断和外部服务不可用状态。长标题、提示词、标签和错误诊断必须换行，不得产生横向溢出。固定尺寸编辑器在窄屏可以切换为只读预览和分步参数面板，不得缩到不可操作。

### 9.3 可观察性

任务指标至少包含排队时长、处理时长、成功/部分成功/失败数、重试数、单位输出成本、模型路由、质量失败原因、人工审核结果和后续复用次数。日志使用内部 ID，不记录原始订单文字、文件内容、签名 URL、访问令牌或完整提示词中的敏感数据。

## 10. 三期交付

### 10.1 POD-1：安全的提取、处理与检索闭环

- 统一作图中心、工具目录、任务中心和我的空间入口；
- 公共任务、版本、审核、质量检查和不可变导出；
- 印花提取、图案处理、基础/深度侵权检测；
- 智能检索和印花图检索；
- 资产域、权利来源和竞品禁止导出门禁。

阶段完成标志：无店铺授权时，用户可以从合格素材完成提取或处理，经审核生成锁定版本和可验证导出包。

### 10.2 POD-2：创意设计与商品素材

- 印花设计全部工具；
- 商品套图、标题草稿、换背景、模特试衣和商品图裂变；
- 结果关联产品、SKU、Listing 图片槽位；
- 套图模板和通用模板复用。

阶段完成标志：已授权输入能够形成经过权利与设计审核的印花系列和完整 Listing 素材候选。

### 10.3 POD-3：个性化履约与生产文件

- 来图定制模板、PSD 解析和批量数据编排；
- Amazon/Etsy 官方授权订单的个性化输入映射；
- 生产图、裁片、UV、矢量履约和不可变生产清单；
- 商品短视频生成；
- 顾客校样、生产检查和下载审计。

TEMU 教程只用于定义可扩展的“用户提供文件包适配器”接口。当前 YummyAI 产品边界不包含 TEMU 店铺接入、抓取、发布或状态回写；如未来扩大平台范围，需先更新主 PRD、连接器架构和安全评审。

## 11. 总体验收场景

1. **服装印花提取：** 从有权使用的服装照片提取印花，校正透视和褶皱，标记补全区域，审核后生成透明底版本。
2. **手机壳设计：** 提取手机壳印花，创建授权设计变体，生成套图并关联指定 Listing 版本。
3. **连续图案：** 生成四方连续图，执行接缝检测，按目标尺寸拼接且不拉伸单元。
4. **风险阻断：** 高风险商标或版权证据使任务无法进入生成、Listing 或导出；报告保留来源、时间和版本。
5. **PSD 模板：** 正确解析蒙版组、文字组、图片组、背景组；同名容器只上传一次，不同容器分别上传。
6. **Amazon 个性化订单：** 经官方授权导入订单，按 SKU 绑定模板，生成校样和生产文件，PII 仅对授权履约人员可见。
7. **裁片生产：** 将印花与定位模板合成，验证裁片、缝纫线、尺寸、DPI、色彩模式和输出格式后生成生产清单。
8. **租户隔离：** 任何任务、索引、模板、结果、风险报告和生产文件都不能跨租户读取或关联。
9. **不可变性：** 重试、重编辑、参数变更和人工调整均产生新版本；已批准版本与导出清单保持不变。
10. **异常恢复：** 批量任务单项失败时成功项可查看和审核，失败项显示原因并可单独重试。

## 12. 成功指标

| 指标 | 定义 |
| --- | --- |
| 任务可追溯率 | 100% 结果可定位到输入版本、参数、模型和运行记录 |
| 权利门禁覆盖率 | 100% 生成、Listing 和导出动作经过资产域与风险门禁 |
| 批量部分失败可恢复率 | 100% 单项失败可诊断并可重试，不丢失成功结果 |
| 生产清单完整率 | 100% 下载的生产文件含尺寸、格式、校验和、来源版本和审核状态 |
| 设计资产复用率 | 按模板、结果、产品和 SKU 统计后续复用，持续提升 |
| 人工审核可解释率 | 100% 退回或风险放行包含结构化原因和审核人 |

## 14. 决策记录

1. 采用统一作图中心，不建设独立于 ERP 的 POD 子系统。
2. 一级导航固定为七个模块，公共检索、任务和空间能力不增加一级分类。
3. 所有 AI 结果必须可追溯并经人工审核后才能进入发布或生产流程。
4. 竞品证据不能转换或导出为可发布资产。
5. 工具限制由服务端能力配置提供，截图参数作为产品行为参考而非永久硬编码。
6. TEMU 仅保留文件适配接口的扩展说明，不进入当前 Amazon/Etsy 店铺集成范围。
