# 共用 AI 模型开发验证（2026-09-14）

本轮将八个既有业务助手接入已保存的 OpenAI／兼容渠道文本模型。默认业务分析模型优先，其次是默认文本模型；同渠道、同模型继承已有分析计价配置。未创建新的凭据存储或数据库表。

## 行为与边界

- 创意分析、订单预审、生产稿预检、PSD 模板配置、SKU 资料包、经营分析、采购分析和售后回复草稿共用模型入口。
- 模型或渠道停用后，后台任务在调用前重新检查；历史分析和费用快照保留。
- 未填单价时记录实际 tokens，费用保持未知，不写入伪造的零元费用账本。组织有金额预算时拒绝未计价任务；本月已有未计价调用时保守阻止金额预算调用。目前没有历史未知费用的自助补记入口。
- 已登记价格的模型沿用单次及组织预算。页面标明按配置估算，单价为 0 不代表渠道免费。
- 图文任务仍要求实际模型支持图片及结构化输出。兼容渠道按模型使用适当的输出 token 参数；错误提示不包含渠道响应正文或凭据。
- 修复首次保存订单制作草稿时，将新建记录的默认版本误当作客户端旧版本而返回 409 的问题；原有并发版本检查保留。

## 实际渠道与订单

按用户指定订单完成一次真实 `gpt-5.6-sol` 预审，经用户配置的 OpenAI 兼容渠道调用，成功分析买家原图并返回通过结构校验的结果。渠道返回输入 11,323 tokens、输出 1,853 tokens；当前管理员登记输入、输出单价均为 0，所以记录为按配置估算 $0，实际账单未验证。此结果只证明本次模型与输入组合可用，不代表其他模型均已实测。

订单制作草稿及预审结果已保存，订单仍为待审核、未推送。未生成生产文件：当前没有对应的已审核图片定制印花、具体商品规格及工艺模板，工厂的尺寸计量边界和条码区域尺寸也待确认。未将测试模板绑定真实订单，未替代人工事实确认、生产审核或放行。客户图片和完整结果留在原有订单私有域，不复制到此文档。
