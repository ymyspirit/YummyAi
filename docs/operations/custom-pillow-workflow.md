# 来图定制异形抱枕操作流程

本流程把可复用商品配置与每笔订单的私有生产稿连接起来。现有平台订单
直接进入审单，不需要重新选品、创作固定印花或发布商品。

## 商品配置

1. 在印花库维护来图方案，包含必填顾客图片、裁切范围、印刷面数和制作说明。
   工艺示意图标为参考素材；未来可选背景、边框等应使用独立的授权素材。
2. 在 SPU 与规格维护每个真实销售尺寸，核对材质、包装和尺寸基准。
   每个规格绑定已确认的通用工艺底稿。工艺参数或事实变更创建新版本。
3. 在产品开发组合印花版本与规格版本生成销售 SKU，点击“确认来图方案”。
   该状态允许订单选用，无需先上传某位顾客的生产图。它不等于刊登资料包
   已通过审核；新刊登仍需实际商品图和完整的审核、封版流程。

## 每笔订单

1. 在审单与履约打开已导入订单，核对原始定制选项和顾客原图。
   Amazon 效果预览只用于对照，制图必须使用顾客原图。
2. 选择对应的销售 SKU 方案，核对固定的印花、规格和工艺版本。
   使用已配置的业务分析模型辅助识别要求，再核对 AI 提示和实际证据。
3. 保存审单结果并推送制作需求，默认由“无人设计 Agent”准备制图任务；
   也可明确选择美工领取。系统创建订单私有项目并导入买家素材；来图方案
   不复制通用底稿的示例图层。所有选定顾客图片均调用默认图像模型保真美化，
   不论顾客是否选择图片美化。保留原图及原始选项，只优化清晰度、曝光、
   色彩与噪点，保持外貌、特征、姿态与比例。任务完成后自动生成未审核新版本；
   失败时在“顾客图片保真美化”中重试，未完成不得提交审核。
   默认 Agent 仍需满足模板字段与区域条件；不支持的复杂要求会明确提示。
4. 在“AI 模型抠图”中选择已配置的 `gpt-image-2.5` 和已美化图片，按订单要求
   保留头部或全身，不再修改美化后的图案；直接选择原图时先执行保真美化。
   中间素材需要真实 alpha；放大核对主体保真、耳朵、下巴、
   胡须和残留背景，检查实际像素。模型结果不合格时保留原图和结果供复核，
   不自动改用本地分割、毛发修边或清理脚本，不用改 DPI 标签冒充分辨率提升。
5. 按订单尺寸确定图案的等比例放置尺寸后，保持抠图图案、胡须、比例与角度
   不变。勾选“保留完整抠图，不按白边内缩裁图”，只调整独立的黑色裁线。
   以脸部、耳朵和下巴的毛发主体为白边参考，向外约 200 px；为连续圆滑
   的过渡可小幅加宽，不沿每根胡须产生细长凸起或密集折点。不得通过裁掉
   胡须、修边、重画或重新缩放图案来迁就裁线；白边不再用作图案遮罩。
   单面背片为水平镜像白片；双面订单另需检查文字正读。
6. 生成“原尺寸待审稿”，下载并核对实际像素、DPI、裁线、条码框和排版。
   普通校对预览最长边为 1600 px；原尺寸待审稿保留完整像素与 DPI。
7. 完成生产前确认并在制图中心提交审核。图稿通过审核后才生成正式生产
   文件；订单版本与生产文件固定关联。需要改图时使用退回与新版本流程。
8. 正式文件可用且实际生产安排确认后，下达生产并选择供应商。按真实
   生产、质检和物流结果登记履约状态。测试不伪造生产或发货记录。

## 当前抱枕工艺参数

| 项目 | 规则 |
| --- | --- |
| 输出 | 150 DPI，PNG 整张白底，RGB 无透明通道，sRGB；中间抠图素材保留 alpha |
| 主体 | 按订单最长边等比例缩放，不把缝边、条码凸框或画布留白计入 |
| 缝边 | 以脸部及耳朵、下巴的主体毛发轮廓为参考，向外约 200 px，约 33.8667 mm；为圆滑过渡可略超出，保留完整胡须与抠图图案 |
| 黑裁线 | 6 px，1.016 mm；主体轮廓连续圆滑，避免锯齿、折点和胡须状凸起，闭合且与底部矩形凸框连为一体 |
| 底部空白凸框 | 500 × 180 px，约 84.6667 × 30.48 mm；尺寸按轮廓路径计 |
| 正反片 | 横向排列，包含裁线后的净距为 100 px |
| 整图 | 包含两片及底部凸框后，四周各留 50 px |
| 细窄部位 | 按供应商的成品测量口径核验不小于 5 cm；不把胡须制作成独立细长裁片 |

像素尺寸核验不能推断缝制后的实物尺寸。图稿审核需结合供应商口径；
原尺寸待审稿不会自动通过订单审核或触发生产下达。

## 测试清理

集成测试使用独立数据库与私有素材桶，在成功或失败后清理。人工验证
如果创建临时数据，也应记录确切 ID，按支持的删除或归档流程清理并检查
列表、搜索和数量。真实订单、商品配置及不可变制作历史应保留。
