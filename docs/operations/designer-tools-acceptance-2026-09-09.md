# 生产画布效率工具验收 · 2026-09-09

## 已交付

在现有生产工作台的“图层”栏增加快捷排版，不增加业务页面：

- 可见主体／字形居中、四边对齐，旋转时保持主体中心。
- 图片宽高默认等比联动、恢复原图比例、主体适应区域。
- 复制图层；已有素材替换和上传替换，保留原素材与占位框中心。
- 不透明背景图等比铺满胎罩；透明素材不允许误用背景铺满。
- 直排／顶部弧形切换，按固定字体度量自动适应弧长。
- 图片有效 DPI 实时提示，后台预检问题定位到当前图层。
- 工作台范围内的保存、复制、撤销重做、毫米微调和删除快捷键；输入框、抠图、勾轮廓及锁定图层的操作保护。

## 验证结果

- Web 生产编辑器单元测试：28 项通过，包含 9 项新增几何与操作边界测试。
- 生产渲染包测试：25 项通过，覆盖大图、真实 DPI、透明通道与正反片。
- 原生产工作台及订单报告 E2E：7 项通过。
- 新增工具 E2E：1 项通过，使用合成图片、真实 API／私有存储／Worker，覆盖居中、等比缩放、旋转撤销、复制、键盘移动、锁定、上传替换、文字排版、保存重开和后台预览。
- 首轮新增 E2E 揭示文字输入框的精确可访问名称不明确；补充显式标签后重跑通过。
- Web typecheck、修改范围 ESLint、Web production build、规则镜像检查通过。
- 1600 px 桌面及 390 px 窄屏截图已检查，未发现水平溢出。In-app Browser 中另行核验已有抱枕草稿的主体居中和撤销恢复，未保存对订单稿的测试改动；控制台无错误。
- 本地 Web／API／Worker 已恢复运行，临时视口覆盖已清除。

截图与日志位于忽略目录 `test-results/designer-tools-*.png`、`output/designer-tools-*.log`，没有提交客户图片或订单数据。

## 工艺边界

居中与适应区域按预览透明边界／字形边界和印刷区域外接矩形计算，并非自动验证异形区域内完全容纳图文。抱枕移动、换图或缩放后必须核对原轮廓，必要时重新生成。不会自动填写条码框宽高，也不会更改 150 DPI、八个订单尺寸或最下方条码要求。生产前仍须核对细窄部位、缝边、尺寸口径与背片文字。

未增加 API、数据库表、依赖或外部图片处理服务，未修改上游 infinite-canvas。本记录仅验收本次工具增量，不代表整个 ERP 发布验收。
