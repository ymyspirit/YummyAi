# 订单生产抠图与修边验证

日期：2026-09-09。本记录是本机功能验证，不是发布候选或工厂成品验收。

## 使用入口

订单工作台 → 导入与定制 → 选择订单 → 制作生产图 → 选中图片图层 → **抠图与修边**。
工具在当前生产工作台内打开；应用后返回同一张生产稿。

- 顾客的原始选项与“仅保留完整头部”等制作范围直接显示在工作区。已知的八个抱枕尺寸和单双面选项可以带入，冲突值与未知值不会猜测补齐。
- 框选范围、保留点、排除点用于本机 SAM 2.1 自动选区；套索、擦除、恢复、画笔大小、柔和度、撤销重做和原图对照用于修边。
- 修边生成新的全尺寸透明 PNG。保留原件和加密修整记录，应用、保存、重新打开后仍可继续修整或从原图恢复。
- 图片的透明边缘与生产裁剪轮廓分别保存；抠图应用后再按订单规格生成白边及裁片轮廓。
- 条码留白必须在最下方。工厂未提供实际宽高，真实测试稿继续留空，并保持待核对状态。

## 真实订单走查

在已有的已核对订单测试稿中识别到：Only Face、10 inch、Single-sided Printing。
先框选完整头部并排除胸口；首轮存在白色口鼻误删与背景碎点，补充口鼻/下巴保留点后恢复，随后使用套索和擦除清理。实际全尺寸素材为 3024 × 4032 px，原件与两步修整记录均保留。

已保存 V3 草稿，生成 10 英寸主体对应的外扩轮廓，并完成真实 Worker 正反片校对预览。重新打开抠图工具可看到原始完整照片和已保存的修边结果。单面背片保留镜像空白轮廓。没有确认正式生产，也没有填写未经工厂确认的条码宽高。

订单号、客户原图、定制附件和测试截图不写入此文档或 Git。

## 发现并修复的问题

1. 软画笔在单击或水平拖动时，SVG 默认滤镜包围盒可能为零，导致浏览器看不到修改。改用显式用户坐标滤镜范围，并验证实际点击、水平线和原图恢复。
2. 大照片嵌入内部 SVG 后触发 XML 长度限制，导致后台预览失败。用超过 10 MiB 的合成 PNG 复现后，给受控内部 SVG 配置适用的解析方式，同时加入 128 MiB 内嵌图片和 132 MiB 总图稿限制。预览、正式出图、重复图片超限拦截及真实订单预览均已验证。

## 仍需人工处理的边界

- 自动选区用于初稿，不是毛发级精修；耳边、胡须、白色口鼻和下巴需放大人工检查。生产轮廓也需工厂工艺核对。
- 150 DPI 标记不会增加原图细节；尺寸基准、条码宽高及细窄处要求仍由美工核对。
- 本机自动选区采用单 API 进程串行限制；多实例部署需按接入文档迁移任务并发控制。
- 完整仓库 `pnpm lint` 仍有三个既有 `artifacts/.../system` 文件中的 23 项无关错误。本次修改文件检查通过，未修改这些产物脚本。
- 工作树原有其他未提交改动。本轮没有提交、发布或声明整个 ERP 阶段完成。
