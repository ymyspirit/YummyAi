# 设计系统开发快照 · 2026-09-12

这份快照保存订单定制资料、生产编辑器、创意画布接入和导航整理的当前实现，便于继续测试和回溯。它不是发布候选，也不表示工厂生产验收已经完成。

## 保存范围

- Amazon TXT 订单报告导入、Custom ZIP 解析、预览、审核及订单来源关联。
- 异形抱枕与定制备胎罩生产编辑器，素材、图层、文字、排版、抠图与毛发边缘细化工具。
- 私有项目资产、不可变设计版本、后台渲染与生产文件预检。
- 独立 Infinite Canvas 插件及接口接入、工作流上下文和订单返回路径。
- ERP 导航、功能搜索、外观与工作台布局。
- 配套数据库迁移、合约、测试、集成和操作文档。

原始客户订单、图片、生成稿、模型权重、运行日志及测试截图均保留在 Git 忽略目录中。Python 运行缓存也已排除。代码规范检查排除与 Git 忽略规则一致的根目录 `artifacts`、`.artifacts` 和 `tmp`，避免将本地交付文件的辅助脚本计作产品源码。
