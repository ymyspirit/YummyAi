# 设计系统测试记录 · 2026-09-12

本轮覆盖订单定制资料进入生产工作台、异形抱枕和备胎罩设计、创意画布、保存恢复、后台渲染与导航。测试使用合成素材；已有客户猫头项目只检查加载、顾客要求和预检结果，没有修改或保存客户图稿。

## 发现并修复

1. **刷新后丢失项目选择。** 从独立生产工作台的下拉框打开项目时，地址未记录项目，刷新会回到新建界面。现在地址同步项目和历史版本，刷新恢复选定文档；历史副本另存、换项目及删除时清理过期参数。订单与创意项目内的编辑器保持原有页面上下文。
2. **创意流程测试遗留生产稿。** 测试创建的工艺底稿与派生生产稿未清理。新增按本次创建 ID 清理的收尾步骤。此前遗留的数据没有批量删除。
3. **完整代码检查误扫生成文件。** ESLint 现在排除 Git 已忽略的交付目录；Python 缓存不进入提交。
4. **GitHub 测试资源和服务不足。** 大图测试保留原始像素、DPI、透明通道和文件容量断言，为共享 CI 资源设置有界超时，并限制工作区并发。CI 增加 ClamAV 和独立画布服务。Docker Hub 的 MinIO 拉取重复失败后，改用官方 Quay 地址，现场核对摘要与本地已有镜像一致。
