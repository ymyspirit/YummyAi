# 订单与创意工作台整合验收

日期：2026-09-09。范围：本地 ERP 页面组织、任务内生产编辑、返回行为及辅助工具入口。

## 交付行为

| 业务 | 入口 | 连续处理方式 |
| --- | --- | --- |
| 每日接单 | 订单工作台 → 导入与定制 | 报告导入、定制核对、原图查看、生产编辑留在当前订单；返回保留筛选、批次、分页和选中行 |
| 新品创作 | 创意设计 → 创意工作台 | 项目步骤、方案预览和审核、工艺底稿配置、生产稿编辑在同一工作台接续；返回保留方案选择和筛选 |
| 文件管理 | 创意设计 → 生产文件与底稿 | 管理已保存的生产稿和通用底稿；每个项目创建时选择产品工艺 |
| 商品展示图 | 创意设计 → 商品套图 | 使用已绑定 SKU 的正式设计生成场景图，保留原有审核条件 |

批量生图、图片处理、设计任务与校样收进辅助工具，旧网址继续可访问、可搜索。旧订单导入网址重定向至订单工作台。画布项目不再混入旧批量生图列表；旧批量页面中指向画布项目的链接回到对应创意项目。

原版 Infinite Canvas 仍使用独立窗口和现有公开插件；上游源码、镜像、SDK 和插件协议未更改。订单与创意的来源、审核和文件域继续分开。保存创建不可变版本；编辑器中未保存的图稿和轮廓在返回时提醒。数字文件完成不自动标记实物生产或发货完成。

## 验证

- Node 24.17.0、pnpm 11.10.0。
- Web 单元测试：55 个文件、251 项通过。
- Web typecheck、Web build、改动文件范围的 ESLint 通过。
- API 集成：订单报告、生产编辑器、画布桥接三个文件，45 项通过，覆盖来源版本、买家原图、租户隔离和文件保护。
- 浏览器：导航、订单报告、生产编辑器、原版画布插件、创意工作流及旧批量工具，共 22 项通过。
- 补充真实订单浏览器验收：1 项通过。真实导入合成 TXT；不允许的示例域名在下载前被拒绝；补传合成 ZIP，经实际扫描、存储、解析和核对后创建备胎罩生产稿。断言使用 512 px 买家原图而不是 1 px 亚马逊预览；保存返回、重新打开仍是同一项目，未再次发送创建请求。
- 在 `127.0.0.1` 下真实完成报告导入、核对、生产稿创建与保存，覆盖 Next 开发服务器规范化内部地址时的误报权限问题。不同端口、协议、跨站请求和生产环境来源不匹配仍被拒绝。
- 检查桌面 1440/1600 px、移动 390/375 px、明暗主题及减少动态效果；订单和创意内编辑均无整页横向溢出。返回按钮、浏览器后退、未保存离开拦截、保存后的重新打开均经浏览器操作验证。
