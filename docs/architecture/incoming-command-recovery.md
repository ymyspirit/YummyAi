# 来料操作的原提交恢复

2026-10-20，R03/R27/R28，B28/B39/B40。本文是来料流程的 Harness 约束。拥有者与原提交已有79条关联验证；实际API进程提交前后中断及独立到期维护的真实周期已有隔离证据。个人编译界面、最终源码全量回归、最新业务配对备份与普通145采用仍未完成。配置暂时不可用时保留原加密副本、恢复原配置后重读的修正还需最终回归。不以成功请求校验替代这些工作。

复用现有 `ProductionMaterialCommandService` 的原输入、权限上限、确认和留存原则，以及当前采购与库存拥有者。业务数据仍由拥有者写入，不通过命令表或 Agent 直接操作库存。

## 原操作和结果

六种操作分别固定发布标准、登记到货、记录检验、核准检验、确认入账和登记实际退回的原填写。命令关联原物料、采购单、到货明细或拒收处置；退回还固定原处置编号。规范输入、请求编号、原操作者、版本及权限上限共同绑定，不能用另一张单或另一位操作者取得旧成功。

准备只保存加密输入，不提前接收货物、确认测量、核准或移动库存。页面展示原填写和原依据，操作者确认执行时只提交命令编号，不再上传一份可变化的新正文。每位操作者在同类操作及同一原对象下至多有一笔未确认结果，先恢复、取消或确认原结果再开始下一笔。

执行在租户非拥有者事务中锁定原命令，复查当前成员、当前权限与原权限上限的交集，以及拥有者的实际版本、核准和剩余数量。业务事实、库存、最小成功结果和审计同笔提交。命令服务调用传入事务的业务拥有者入口，不调用另开事务后已经自行提交的接口。

这些命令只执行有界数据库操作，不调用外部工厂、物流、店铺、模型或支付，不增加外部请求租约。数据库连接或进程在提交前退出时整笔回滚，原命令仍待核对；提交后响应丢失时，通过同一命令读取原结果。不得因超时直接生成新请求或自动重放其他业务动作。

业务冲突不覆盖原输入。版本变化或不再满足条件时，页面保留原提交并明确显示需核对的依据；恢复不能把原版本替换成当前版本。未知传输结果先读取原状态；取消只取消尚未执行的准备，不撤销已经真实入账的货物。确认结果只清除不再需要的填写副本，不删除业务事实及其结果引用。

## 当前读取和隐私

输入使用独立加密域，不复用模型凭据、API Client/Webhook、店铺或订单隐私密钥。生产必须明确配置；本地开发可沿用已确认的环境密钥派生方式，但不能重置现有身份、会话或其他密钥。原输入不得出现在日志、URL、浏览器持久存储或一般工作区列表中。

读取命令仍检查本人、租户和原对象的当前读取权。读取失权、身份变化或真正提交失权后清除页面的私有填写与旧响应；在途旧成功响应不能重新显示已失权内容。普通版本冲突或临时网络失败保留当前草稿，不能误判为清除成功。

原权限快照不能授权新工作。读取已成功事实和执行新命令分别判断；没有当前读取权时不显示私有输入或详情，也不能把权限错误当作业务失败并覆盖已经真实成功的结果。

## 到期和运行

原填写保留期限计划为七天；过期的待执行命令停止执行。成功、取消、失效等结果和业务事实保持，过期或操作者确认后仅清除加密填写。原正文缺失、无法解密或校验不一致时明确停止，不从当前页面或旧业务事实猜测补回。

独立维护以数据库时间、租户RLS、空业务权限和有界批次清理过期填写。读取时的过期处理不能冒充无人访问时的后台物理清除。采用前须观察实际周期、停止/重启、批次结果及失败延后；不得借此启动原有业务队列消费者。

## 必须取得的证据

- 准备与执行回应分别丢失后，同一操作者在新会话恢复原命令和原结果，库存只入账一次。
- 实际API进程在提交前后退出并重新启动，分别证明原准备保持或真实结果保持；浏览器拦截不能替代全部进程证据。
- 更改正文、原对象、原退回处置或操作者不能重用原请求；并发执行只有一个业务事实及成功结果。
- 后段审计或结果保存失败回滚库存与收货；权限撤销、窄写入范围和依据修订不能借用旧授权执行。
- 加密输入到期或损坏不能执行，原成功事实与最小结果仍保持；独立维护不读取业务队列正文或消费旧任务。
- 真实个人页面覆盖刷新、失权、只读、草稿保留、手机显示、结果确认和取消；测试资源与原始输出检查后清理。
