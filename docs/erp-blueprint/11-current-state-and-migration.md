## 4. 迁移步骤

1. **盘点**：对象类型、数量、版本、订单状态、金额、工厂、文件校验值、资料保留期与未完成外部意图。
2. **映射**：现有 ID 与目标语义一一对应；缺失和多义进入人工台账，不新造来源事实。
3. **扩展**：新增可空字段、版本或侧表，旧代码继续可读；迁移在隔离副本演练。
4. **回填**：只从已存在的权威证据生成投影，并记录 mapper version、来源、统计和错误。
5. **对照**：新旧读取并行比较数量、金额、文件、权限和关键状态；每个事实只有一个写入拥有者。
6. **小范围切换**：按租户/品类/流程启用新入口，监控业务错误与恢复；保留旧读入口和安全人工处理。
7. **扩大和收尾**：准出后扩大，旧路径停止写入；确认兼容窗口后才移除无用结构。

不采用无对账的双写。外部付费意图、已发生生产和发货不允许因重放迁移再次执行。
