从可履约的商品方案开始，逐件追踪订单和成本。
本页展示目标设计，不代表 ERP 已实现。

## A 两条主线 {span=2}

| 主线 | 核心任务 | 交付结果 |
| --- | --- | --- |
| 自营经营 | 商品、设计、上架、广告、订单 | 可复用的商品方案与经营证据 |
| 工厂履约 | 能力、产能、制作、质检、物流 | 指定文件、数量、交期和真实回执 |

## B 从商品到交付 {span=2}

~~~flow LR
商品方案 -> 销售资料: 固定版本
销售资料 -> 订单商品: 接单与映射
订单商品 -> 制作审核: 原图与规则
制作审核 -> 工厂交付: 文件与数量
工厂交付 -> 履约利润: 质检与费用
~~~

## C 系统职责

~~~tree
YummyAI
  Web 工作台
    运营与设计
    受限工厂协同
  API 业务服务
    认证 权限 事务
    产品 订单 财务
  Worker
    制作 同步 对账
  数据与文件
    PostgreSQL RLS
    私有分域存储
~~~

## D 逐步建设

| 阶段 | 可验收的交付 |
| --- | --- |
| S0 | 范围、买建判断与现状基线 |
| S1 | 权限、主数据与可靠运行 |
| S2 | 商品方案与审核导出包 |
| S3 | 完整定制资料与审单 |
| S4 | 正式文件与独立审核 |
| S5 | 工厂、排产、质检与返工 |
| S6 | 采购、交运、售后与利润 |
| S7 | 增长、运维与复制验证 |

## E 智能体材料的采用方式

- 买建判断看维护能力和独特需求。
- 知识、方法和业务事实分别管理。
- 先验证单条流程，再扩大自动化。
- 比较单位合格交付的完全成本。
- 主观模型评分保留为候选假设。
- 生产、退款与付费操作单独授权。
