## 1. 产品定义

YummyAI 为自营 Amazon Custom 团队提供从商品开发到订单利润的经营工作台，并连接供应商、实际生产工厂和物流服务，形成可追踪、可核验的定制履约网络。先验证自营与工厂协同，再决定是否开放给外部卖家。

平台交付的核心资产是“可持续履约的定制商品方案”：产品事实、定制定义、设计模板、生产配方、供应能力、销售资料、成本与交期共同组成方案。订单执行固定当时有效的版本，不随今天的商品和规则变化。

## 5. 第一批要完成的业务结果

1. 选一个有真实工艺标准和已核验工厂的商品，建立完整商品方案。
2. 生成可审核、可复用且版本固定的上架交付包。
3. 导入获授权订单，并核对每个商品的文字、选项、原图和来源。
4. 制作和审核真实生产文件，工厂针对指定版本确认接受。
5. 记录质检、实际交运、售后和费用，算出资料完整的订单利润。
6. 用第二家工厂或第二个品类验证模型可复用，而非只跑通一个特例。

## 6. 不变的建设原则

- 租户来自认证成员关系；所有租户业务操作通过 withTenant 和非 owner 数据库角色，启用强制 RLS。
- 顾客素材、原创授权素材和竞品研究材料分域。研究材料不能成为生产或发布素材。
- 产品、模板、规则、审核稿、生产交付、报价和财务证据按版本保存。纠错追加新版本或冲销，不覆盖历史事实。
- 预览、操作员审核、客户确认、工厂接受、实际生产放行和实际交运分别记录。
- 未知成本、产能、地址、接口权限和交期显示未知，不能当作零或自动确认。
- 外部付费操作先记录意图；结果不确定时查原意图，避免重复购单或重复支付。
- 前端采用白、黑、蓝的工作型 ERP 语言，使用开源图标，保留进场、过渡、退场与减少动态效果模式。
- 本目录维护当前建设规格；按已授权范围增量重构现有模块，保护无关未提交改动和历史业务版本。
