## 8. 三个运行手册摘要

### Worker 中断或队列积压

确认进程和队列句柄 → 查看安全任务状态与最老年龄 → 修复基础依赖 → 让租约与 dispatcher 恢复 → 核对重复执行防护 → 重新收集完成与清理证据。不要删除队列后凭记忆重建任务。

### 外部付费结果不确定

暂停该意图的再次执行 → 固定账户、原参考和预算占用 → 查询提供商实际状态 → 保存真实费用和产物 → 通过专门纠错流程解决差异。一次未查询到不能作为重复购买依据。

### PII 泄漏或错误生产

停止受影响下载或自动动作 → 撤销授权与保护现场 → 确定对象、版本和外部接收范围 → 由责任人按适用政策处理通知与补救 → 修复并重新验收。日志只保存必要安全证据，不能为调查再扩散原始资料。
