## 2. 三种工作模式

人工模式：人在画布编辑和选择候选，系统负责版本、权限与文件检查。

辅助模式：Agent 按授权生成候选，人确认内容与业务结果。

受控自动模式：固定任务按配方执行、检查和有限修正，异常暂停并提供接管。自动技术通过不能代替操作员批准、工厂接受或生产放行。是否允许减少某项人工审核，需要独立业务规则、评测与授权，不能由 Agent 自行决定。
