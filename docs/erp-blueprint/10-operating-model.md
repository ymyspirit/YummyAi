## 1. 谁对结果负责

| 工作 | 经营负责人 | 商品/运营 | 设计/审核 | 生产/供应 | 财务/物流 | 技术维护 |
| --- | --- | --- | --- | --- | --- | --- |
| 商品方向与经济边界 | A | R | C | C | C | C |
| 产品事实和样品 | A | R | C | R | C | C |
| 销售方案和投放 | A | R | C | C | C | C |
| 审单与制作 | C | R | A/R | C | C | C |
| 工厂排产和质量 | C | C | C | A/R | C | C |
| 外部购单和实际交运 | C | C | C | R | A/R | C |
| 收支证据与对账 | A | C | C | R | R | C |
| 权限、接口和恢复 | A | C | C | C | C | R |

A 为最终负责，R 为执行，C 为参与核对。人数少可兼任，但一次操作的权限和审核角色必须明确。重大差异、异常退款或生产放行是否要求第二人审核，由风险与授权政策确定，不由 Agent 自行决定。

公司负责数据、合规、供应链和维护预算；业务负责人承担商品与交付结果；Agent 执行授权任务并报告产物。知识、方法、数据和运行状态应能交接，不能只保存在某人的聊天历史。

## 2. 工厂网络从准入到退出

1. **建档**：分开登记商务主体、实际生产地点、联系人、发货与退货地点。
2. **样品**：固定材料、工艺、色彩、尺寸口径、文件规范与验收证据。
3. **能力启用**：确认承接工序、整件或部分加工、MOQ、报价、交期、有效期、产能依据。
4. **试单**：少量获授权真实订单，记录接单、文件接受、生产、质检、交运与返工。
5. **持续合作**：维护能力与报价版本、工厂日历、明确变更通知和异常升级。
6. **暂停/退出**：停止新分配，处理在制、未交运、账单与顾客资料；历史证据保留。

商务条款至少明确：文件与图案使用范围、保密及顾客资料处理、不可擅自换厂/换料、数量与质量标准、截单和交期、返工/赔偿/运费责任、报价有效期、账期、争议及退出交接。具体合同由业务与适用专业人员核对，系统保存有效版本与证据。

## 3. 国内与美国节点如何选择

模型同时支持中国生产后跨境交付、美国本地生产、以及经确认的半成品库存加本地加工。是否采用取决于真实工艺、交期、总成本和资金占用。

原产地、生产地点、发货地点和库存地点分开记录。美国仓发货不自动证明美国制造。路线承诺使用工厂当地工作日历、实际完工时间、物流服务条件和已核验时效。

先检查工艺、材料、模板、交期和产能硬条件；合格候选再比较总成本、质量和履约记录。表现样本量与时间范围必须可见，不以一笔快单推断稳定产能。

## 4. 供应商表现与责任

独立展示按时接单率、指定文件一次接受率、生产准时率、质检不良率、实际交运及时率、返工结案周期及账单差异。时间从具体承诺与事件计算，不能把 ERP 内部登记时间当真实工厂动作。

评分如需加权，由经营负责人发布带版本的政策并做敏感性分析。合规、样品失败和不能满足工艺是硬门槛，不能用便宜或高总分抵消。

## 5. 三本相关但不同的账

| 账 | 用途 | 来源 |
| --- | --- | --- |
| 经营测算 | 选品、定价、广告上限和供应方案比较 | 已核验报价与明确假设 |
| 实际业务成本 | 解释订单、工厂、物流和售后真实消耗 | 生产、采购、面单、返工及账单证据 |
| 会计与现金 | 应收应付、实际付款、税务与法定报告 | 经确认财务系统、发票与付款来源 |

报价不等于已发生费用，应付不等于已付款。成本按业务发生时间与账单观察时间分别记录。系统不能以“完成任务”自动生成已支付事实。

## 6. 利润口径

商品预估贡献 = 预估净收入 − 已知变动成本 − 明确假设的售后与广告成本。所有假设带有效时间和来源。

订单已确认贡献 = 已确认可归属净收入 − 已确认生产/材料/包装/制图/物流/售后等变动成本 − 该口径规定的分摊费用。任何必需成本缺失时标记不完整。

净收入排除不应计为收入的代收税，并按实际口径处理折扣与退款。共享面单、整单费用和广告只按明确定义分摊；无法合理分配的金额保留在订单或期间层，不强行压到 SKU。

广告归因订单不等于真实全部订单的因果来源。管理分摊广告费必须标清其规则、期间和覆盖，不能伪装平台提供了逐单花费。

## 7. AI 和自建的完全成本

以同一批验收通过的交付计算：工具/订阅、API、数据采购、服务器与存储、开发摊销、维护、复核、失败返工、故障与迁移成本。记录每单人工分钟与不可自动化交接。

月净收益变化 = 可证明的人工节省 + 可归属新增贡献 + 减少的差错损失 − 新增完全成本。收入变化不能只因上线 Agent 就归因给 Agent，应保留基线及同期影响说明。

团队规模帮助估计协作成本，但不直接决定自建。没有持续维护者、稳定数据接口或可证明收益的模块，优先采购、集成或保留受控人工路径。用户材料的模型评分只作候选线索，见 [14](14-critical-reading-agent-decisions.md)。

## 8. 日常运营节奏

- 每日：检查到期订单、缺图与审单、待审核稿、工厂待接单、交运风险和外部不确定意图。
- 每周：复盘返工、单均人工耗时、资料完整度、供应商表现、广告建议与实际利润。
- 每月：核对供应商账单、库存与财务差异、模型/工具完全成本、权限和接口健康。
- 变更时：新工艺、工厂、模板、规则或模型先试验，确认影响范围后对未来任务生效。

## 9. 上手与接管

每个角色有 1 页 SOP、演示样本、异常处理和接管联系人。至少练习：缺图补充、旧稿驳回、工厂拒收、购单结果不明、地址更正、部分退款及恢复后资料清理。

试点建议选择 30—50 条具有代表性的获授权商品行，覆盖常见与异常类型；该数量只用于初步流程学习，不足以证明高可靠无人运行。真实订单是否纳入试点由经营负责人确认，技术测试数据单独管理。

扩大范围前检查关键错误为零、异常可接管、成本覆盖完整、样品质量和工厂承诺有依据；其他目标与基线对照后确定，不凭演示单设定通用百分比。

## 10. 对外服务的条件与收费假设

自营与工厂网络稳定后，再小范围邀请外部卖家。先验证：租户开通、安全、数据归属、店铺授权、服务责任、工厂价格、异常赔付、账单、支持成本和退出导出。

可讨论三类收入：软件与工作台订阅；商品开发/素材/制图等明确交付服务；生产履约协调服务。生产、物流和售后责任透明，平台服务费与供应商成本分别显示，避免无法核对的隐含收费。

本版不确定售价、抽佣比例或保底收益。需要真实交付成本、支持时间、客户意愿和风险预算后再做商业试验。R48 可选，不阻断自营完整 ERP 的建设和验收。
