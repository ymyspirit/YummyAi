## 1. 产品定位与数据边界

入口为知识中心的 `/knowledge`。知识保存有来源、适用范围和版本的运营依据。现有主题为 Listing、广告、客服售后、市场研究、运营 SOP；来源分官方、团队、案例。每条记录维护负责人、核验日、复核日、平台、市场及可选 SPU。

ERP 保存当前产品、订单、成本、库存和事务事实；规则中心保存约束与可信执行绑定；方法库保存版本化步骤；知识提供解释和引用。文章中的数值或经验不能覆盖商品、预算、订单或生产门禁。人工指南未经代码实现与验证不能成为自动执行规则。

规格事实 V2 的材质、结构、测量与包装只能由商品模块保存核验版本。知识中的供应商参数或尺寸换算可形成候选并提供引用，不能自动填满未知值或替运营确认；生产和订单仍使用各自固定的规格版本。旧记录不补造今天的确认，见[规格事实契约](../integration/specification-facts.md)。

## 2. 从资料到发布版

方法治理复用原生注册表，草稿、提交、精确版本复核、发布和停用分别留证。九类辅助固定方法发布版，新版本不替换旧输入，撤销代次阻止旧选择在重新启用后复活。正文、步骤和工具来自代码，补充说明留在资料域。`/knowledge/methods` 支持分页选择当前发布的通用知识，明确展示旧版本固定引用及其当前可用性；来源无效时不能提交或发布。未保存草稿在并发冲突后保留，撤销读取权则清除草稿和详情，并丢弃旧请求的晚到响应。具体实现和验证范围见 [方法治理](../integration/agent-methods.md)，完整 B14 和业务验收仍在建设。

文档导入 → 扫描与有界解析 → 原件/来源快照 → 确定性候选分段 → 编辑和接受/拒绝 → 草稿 → 提交与 diff 复核 → 明确发布。

当前集成规范支持 UTF-8 TXT/Markdown/CSV、文字 PDF 和 DOCX，单文件 5 MiB、提取正文 200,000 字符；扫描 PDF 没有内置 OCR。加密、损坏和不安全文件需给出诊断。候选分段不是模型已总结或已核验的知识。

接受候选只生成草稿或修订；草稿不检索。新草稿不撤销旧有效发布版。发布、停用、归档均保留历史引用。旧 revision 更新返回冲突。发布范围不得超出来源授权范围。

用户提供的智能体 PDF 可作为团队方法材料，原文、推论、待验证声明分开；REA 转换和分析结果不能自动发布。实际导入、审核和发布须各有记录，本轮规格升级不执行这些业务动作。

当前发布方法的执行证据累计覆盖九类辅助及独立看图审核。知识问答、订单预审和 SKU 资料包另有真实浏览器证据；其余六类与独立审核在实际业务服务、RLS 和处理器路径验证固定旧版、新输入采用新版及当前读取权，模型传输仍为合成。预览与任务结果显示各自的方法版本，旧任务链接可打开原历史版；发布更新不会覆盖旧输入。范围见 [其余业务方法验证](../project-control/REMAINING_METHODS_DELIVERY_20261017.md)。workflow/POD 现复用相同方法及知识拥有者，在原父/子输入固定各自发布版；所属写事务通过来源共享锁与知识撤回串行，旧知识不替换成新发布版，方法来源不成为商品事实。具体原生路径与历史缺失边界见 [执行方法治理](../integration/execution-methods.md)。其他工具、真实提供方质量及完整验收继续，不能由目录或局部证据替代。

## 3. 检索与 Harness 输入

POD 稳定结果方法复用原生方法和知识来源治理；冻结旧代码定义用于兼容原发布引用，不把旧界面字段或知识说明变为生产批准。新版采用、历史终态缺失和当前权限边界见 [产物交接契约](../integration/pod-completion.md)。

候选、规格适配/扩图、PSD 编译、套图和 Studio 的新原执行固定同一方法选择与知识引用；实际执行及采用仍复核来源有效性和当前权限。已提交的原响应与已知费用按原保留条件保存，不能借恢复替换为新知识或绕过撤回。见[创作持久执行](../integration/creative-execution.md)，其当前执行操作的本地边界见[操作契约](../integration/creative-execution-operator.md)，正常部署和真实业务验收仍待完成。

订单设计的模板/来图抱枕方法复用同一知识拥有者，注册、步骤与采用原响应时复核
固定来源；发布新版不替换仍有效的原引用。已停用来源、撤销代次或当前读取权
不能由恢复操作绕过，知识说明不改变原订单工艺和模型预算。历史方法与制作交接
按当前读取权展示，详见 [原方法与制作交接](../integration/order-design-completion.md)。

先按租户、当前权限、平台/市场/SPU、发布状态、有效期、来源和阻断冲突过滤，再做检索排序。当前为中英文关键词检索；没有向量服务或全自动学习能力。后续只有固定评测证明召回不足且维护成本合理时，才评估 PostgreSQL 全文/向量或独立服务。

模型输入固定 entry/version/checksum、来源、摘录和定位，并与 ERP 事实分别标注。当前普通检索最多六个引用；账户证据必须明确选定有权店铺，不能混入普通知识搜索。范围变化创建新的对话上下文，不能沿用另一店铺的证据。

每次追问检索当下可用依据；历史回答仅作对话背景。有事实但没有支持引用时不得当作已核实结论。知识编辑或归档不会改写旧运行的固定输入；再次执行仍要检查当前权限和保留期。

九类辅助以知识拥有者的同一套来源、有效期和冲突判断复核固定引用。发布 v2 不自动替换或否定已固定且仍可用的 v1；停用、归档、证据失效或阻断冲突会停止执行或采用响应。提交前停止不产生模型调用；请求途中失效仍保留原响应检查点与已知费用。已确认的脱敏账户证据不因原件按期清理而失效，店铺权限和脱敏内容有效性仍需复核。见 [Harness 输入依据](../integration/agent-harness.md#assist-input-authority-2026-10-16)。

知识问答另固定代码注册的方法与工具引用；方法正文来自已支持执行版本，知识/PDF 内容留在资料域。外部资料不能注册工具、替换方法或扩大当前权限。客户端提交 executionContract 等服务端字段按非法参数返回 400，不创建任务。原生方法与工具的实际执行范围见 [Tool/Skill 契约](../integration/agent-harness.md#native-tool-and-skill-contracts-2026-10-16)。

| 能力 | 产品行为与限制 |
| --- | --- |

## 5. 隐私和原件

沿用独立知识证据加密域、租户 RLS、审计及受权下载。原件和引用元数据分开管理；原件默认保留七天、可配一至三十天，不能把永久可下载作为知识引用条件。需要历史依据时保存获准的摘录、校验值和版本，并明确原件已清理。

账户原始报表和买家资料不进入通用知识正文。脱敏确认、当前店铺权限、资料有效期在调用前校验；正文、凭据、签名 URL 和原始提示词不进队列或明文日志。

## 制造知识与业务事实 · 1.1.33

供应商工艺说明、PDF、SOP及经验可作为有来源/版本/适用范围的知识，用于解释和起草；只有ERP拥有者中的已批准制造版本、原生产绑定、实际交付快照及人员回执构成对应业务事实。检索到的新知识不能静默替换旧生产BOM、规则快照或旧包，更不能代造供料、实际耗用、工厂接受、完工和质检。

工厂/Agent只取得当前获授权任务的最小材料、工序和明确生产说明，内部BOM备注、成本及库存事实不因进入检索而获得共享权。新V3接受必须指向原制造计划校验值；历史V1/V2缺清单保持未知，不通过知识库补造。见[制造交付契约](../integration/manufacturing-delivery.md)。

PRD 1.1.23 的[创作执行操作入口](../integration/creative-execution-operator.md)复用原方法/知识选择与原拥有者，保留原输入及费用。申请续做仍复核当前原准入，人工核对不替代终态恢复、账单验真或业务批准；普通部署和完整验收继续。
