## 2. 五张必须先写清楚的任务卡

### B24：订单映射

- Given 同一平台 SKU 在两个时间区间对应不同选款配方，When 导入跨区间订单，Then 每行按下单时间固定正确版本。
- Given 缺少款式或重叠映射，When 审单，Then 返回具体缺项或歧义，不默认选择最新配方。
- 回归：重复导入、旧订单无快照、选款不误印为文字、一个订单多行不同结果。
- 涉及：packages/contracts、packages/database、apps/api/src/orders 与现有 sales-compositions 服务；不能直接跨模块写渠道映射表。

### B30：实际生产文件检查

- Given 模板固定尺寸口径与供应规范，When 服务端读取实际输出字节，Then 给出可重现的像素、PPI、几何、格式和色彩报告。
- Given 像素不足但 DPI 标签被调高，Then 仍失败；技术失败不能被前端标记绕过。
- Given 仅需几何修正，Then 不重新生成或改变授权图案。
- 回归：旧模板参数、坏图、透明边界、正反面、失败修复和检查版本变化。

### B36：工厂范围

- Given 协作者分配到工厂 A 的任务，When 请求 B 的任务或 A 未分配文件，Then 返回不可见或无权。
- Given 合作或分配撤销，When 旧页面续签文件或提交接受，Then 拒绝且不改变业务状态。
- 回归：多卖家服务同一工厂、链接共享、任务到期和必要直发地址最小化。

### B41：购单结果不确定

- Given 预算和稳定客户参考已保存，When 提供商可能成功但响应超时，Then 保存不确定状态并只查原意图。
- Given 第一次查单未找到，Then 不自动再买；界面显示安全下一步与占用预算。
- 回归：重复点击、Worker 崩溃、部分面单、实际费用超预算、旧地址与供应商不支持撤单。

### B46：利润完整性

- Given 一笔生产费缺失或汇率无来源，When 计算利润，Then 显示不完整及缺项，不补零或自动选汇率。
- Given 同一账单重复导入或费用被冲销替换，Then 不重复计费且历史计算可复现。
- 回归：订单共享费用、SKU 无法分配、税额、退款、补做、广告管理分摊及多币种舍入。
