# 订单定制需求解释与无人设计先行

订单详情按顾客实际填写的文案、同组字体/颜色、原图、裁切、尺寸、单双面及备注整理要求。
常见选项由确定性规则识别，原始导入资料保留在折叠区。运营不需要把每个导入行都映射成模板字段。
资料齐全后确认审单、明确推送，由无人设计先生成待审稿；运营驳回时填写原因并交给美工制作新版本。
确认审单以当前运营身份，在同一事务中核对本次原始报告来源并保存制作需求；保存草稿、待补资料不会形成来源确认，保存失败也不会留下单独的来源审核。Agent 不负责代替运营确认资料。
无人设计能力不足或执行中断会显示具体处理原因，不能把保存成功当成已经出稿。

## 原始分组与样式

- 原始 `AmazonCustomDocument.raw` 继续由报告模块加密保管。`requirementSources` 经原模块的当前权限、来源版本和保留期检查读取；不重新下载或改写历史资料。
- `TextContainerCustomization` 内的字体和颜色只属于本组文本。页面级样式不能扩散到其他组、图片、尺寸或工艺选项；旧扁平记录里继承来的 `font/color` 不再视为人工确认。
- 文案逐字保留，包括空格。空的 `Custom your text` 表示没有印字内容，字体选项本身不会成为印字。
- 颜色名称与真实色值分开。`CustomColor` 没有附带 `#RRGGBB` 时明确待核对，不能自动使用黑色；原始资料明确提供黑色时正常保留。
- 人工编辑本组样式须明确采用，写入 `styleOverride.source=operator`。临时未采用的输入不会悄然保存或确认。
- 旧资料没有原始分组时标为 `legacy_unresolved`，保留原文并说明缺失；不根据相邻行猜测样式。

## 检查与模型分析

`POST /v1/order-centers/lines/:id/intake-check` 检查当前草稿，返回唯一匹配后的 `normalizedDraft` 和 `requirements`。
`OrderRequirementInterpretation` 固定订单、修订、投影、报告来源及制作版本，包含 `sources/texts/notes/options/coverage/unresolved`。
`basis.draftChecksum` 是**完整原请求草稿**规范 JSON 的 SHA-256，不能改用规范化结果的哈希。
返回迟到、输入变化或订单/身份变化时旧解释不能覆盖当前草稿。

“AI 分析并填写”使用原 `order_review` Assist，并携带当前未保存草稿。
模型只提出 `orderFieldBindings`，每个来源、目标、语义和引用都在本次服务端输入范围内验证；不能创造文案、字体或色值，也不能把字体/颜色选择器当成打印文案。
结果采用时再次核对原草稿与当前上下文，只填入草稿，仍由运营保存与确认；不会自动推送或批准生产。
置信度低于 0.85 的绑定保留为待核对，不自动填入；即使置信度低，非法来源或错误引用仍会被拒绝。

打开页面和常规匹配不调用模型。显式分析前选择模型，显示实际配置的输入/输出单价及单任务上限；缺少报价不能发起。
并发、组织单次/月度预算和费用预留继续由现有服务端事务控制。模型配置或预算错误显示固定原因并保留填写，未知上游错误正文不外露。
订单定制解释使用独立补充指令版本 `order-requirements-2026-10-27-v1`、方法 v2 和严格模型输出格式。补充版本实际写入指令，并由完整指令、输出格式的策略摘要及方法契约固定；共同基础提示继续使用原 v6，沿用原人工视觉预检的“基础指令加版本化补充”方式。其他分析与知识评测保持原指令、方法及输出格式，数据库原事务校验不改。原对外结果中的新增字段不设默认值，旧封存输入、输出和账本不改，不能用新契约重新发送旧未完成订单分析任务。

## 候选审核与美工接管

推送固定原不可变需求修订、同源解释、模板、制造配方、规则快照和模型路由。新需求解释使用独立方法版本，旧任务沿原版本恢复，不补写今天的规则。
无人设计完成后保留真实步骤、费用、制作版本和校样完成证据。
只有当前推送修订、当前编辑版本与完成证据一致时，列表投影 `designCandidateReview=true` 并显示待审图；实际 `artwork` 状态和正式生产批准不被伪造。

运营驳回须具有审核权限，提交当前候选版本与原因。原任务在同事务内标为人工接管，原候选和费用历史保留；之后美工制作、重新送审时当前执行岗位仍为美工。
通过审核继续使用原技术检查、人工视觉确认、客户校样与生产放行门禁，候选完成不等于 `productionReady`。
真实非空印字缺少可执行字库/文字区域时明确停止处理，不能悄用替代字体、黑色或删除文字生成合格结论。

本批无新增数据库表或环境变量。日用后台任务是否启用、模型真实质量与实际付费调用分别验收；合成模型测试不代表真实生产订单已自动完成。
