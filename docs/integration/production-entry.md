# 生产入口与原提交恢复

2026-10-20 · 对应完整平台 B33/B35/B37 等在建工作。本文记录本轮契约与验证边界，完整平台和正式运行仍未验收。

## 审核稿、单商品与拆厂

生产中心保留整单审核稿下达，并增加“按商品或拆厂安排生产”。明确填写本次数量、制造版本、销售 SKU 数量单位、具体工厂能力、完工时间和说明。工厂选择按本次数量检查。共享读取和写入使用同一数量计算：已取消原生产若已有实际交运证据，仍占用原订购数量；面单、异常状态或取消文字不能把已交运数量释放出来。

`GET /v1/order-centers/lines/:id/production-availability` 返回原订购数、原生产已安排数、剩余数、当前是否具有租户级下达权限，以及审单修订与投影版本。必须有当前订单与私有资料读取权，并复查原订单工作资料可用。BFF 验证返回的商品 ID、数量关系，拒绝调用者租户参数。客户校样不需要时可继续；需要校样时，必须批准且仍与当前稿一致。

旧质检补做、实物组返工和新审核稿返工都必须等待制造依据就绪。新稿返工重新读取实际角色、当前审核稿及正式 JPG；固定工艺要求为只读文本，运营补充说明另填。短暂读取失败保留数量、交期、原因和补充说明，重新核对成功前禁止创建；失权、资料到期或不可访问时清除私有依据。

## 已审核设计直接生产

生产中心的“已审核设计直接生产”打开 `/production?view=native`。只读取未建立审单工作项的原生标准化订单商品。已进入审单的商品继续使用原审核稿，不允许通过重新声明商品规格覆盖其历史来源。

操作员依次明确选择当前完整产品规格、实际 SKU 的已审核设计、所列授权生产文件、已批准采购路由和当前采购单、已批准制造版本，以及属于该供应商的具体工厂能力。填写本次产品及设计确认依据、完工时间、生产说明，并核对原订购数量。当前直接命令固定整份原订购数量；部分数量和拆厂使用审核稿入口，不能给原命令传入未支持的数量。

| 接口 | 契约 |
| --- | --- |
| `GET /v1/order-centers/native?q=&after=` | 当前租户订单读取；每页 25 商品；当前写入能力与权限标识 |
| `GET /v1/order-centers/native/lines/:id?specificationVersionId=` | 实际商品关联、当前规格、相容且可读取的审核设计与授权文件、路由采购来源和已有安排 |
| `GET /v1/order-centers/native/lines/:id/factories` | 严格要求规格、路由和采购版本，按原订购数及该供应商核对工厂能力 |
| `GET /v1/order-centers/lines/:id/manufacturing?nativeSpecificationVersionId=` | 仅无审单商品可明确查询本次当前产品规格；与原生产 ID 互斥，不能替代原绑定 |
| `POST /v1/order-centers/native/orders/:id/production` | 委托现有 `OrderProductionService.create`；原 `POST /v1/orders/:id/production` 保留；返回固定商品与订单的最小回执 |

读取在非拥有者应用角色的租户事务中复查当前成员。商品、设计和素材分别沿用所属模块权限及自身对象范围；某设计或素材不在当前范围内时不作为可选来源。规格必须属于实际 SKU 的 SPU 并为当前完整版本；竞争对手、顾客私有文件、失效授权和不相容画布印刷规格不能作为直接生产来源。

订单从未提供私有资料时可读取原有非明文顾客事实。存在私有资料但已到期或匿名化时不恢复其可用性，不补造顾客资料。原生产已占满时显示已有安排并阻止重复创建。采购版本必须属于同一订单与供应商，固定同一路由、本商品和完全相同的原订购数；仅“有一张批准采购单”不足以放行。

直接入口当前仅允许 `rectangular_print` 的已审核设计来源。抱枕和轮胎罩等仍需其审核生产稿与制作几何。创建结果是内部 planned 生产安排，不代表文件已提交工厂、工厂已接单、实际生产、质检或出库。没有增加真实工厂交易或平台发布。

## 原请求恢复与输入错误

整单、单商品及直接生产现接通[服务端持久恢复](production-command-recovery.md)，准备响应丢失后刷新可找回本人原确认，执行仅提交意图编号。交付包、工厂回执和新稿返工仍为当前页面内的原路径、输入与幂等编号，后续逐项适配。未知时阻止重建冲突请求，由操作员明确恢复；可信回执后的列表失败只重新读取。

本人会话、调用者权限和资料范围仍由服务器重新检查。BFF 只允许明确路径、查询字段、同源 JSON 写入，校验原商品及订单回执，保留私有 no-store 响应。直接入口的 REST 输入在调用业务命令前把格式错误返回为已知 400，避免输出原输入；真实业务或输出失败继续作为服务器错误处理。该适配尚未扩大到所有旧模块。

首批三类持久恢复已有刷新/本人新会话的本地证据，0136未进入普通环境，不能扩大到其他页面或完整Harness。B34真实日历、并发产能占用与释放，B40准确物料移转、消耗和责任记录，以及其他工作包继续。
