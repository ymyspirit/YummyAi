# 原生设计、创意审核与 SKU 绑定授权

2026-10-19 · PRD 1.1.20 · R01/R08/R13/R18，B06/B08/B15/B18。

## 拥有者和实际事务

核对开源 [CASL 的对象条件授权](https://github.com/stalniy/casl)与
[PostgreSQL 的事务锁](https://www.postgresql.org/docs/current/explicit-locking.html)后，
复用原生 authz、非 owner RLS、素材门禁及目录 SKU 访问，不增加授权引擎或依赖。
DesignService 的公共命令先检查操作权限，DrizzleDesignRepository 的实际事务
再检查原请求与当前成员的权限交集、具体拥有者及当前业务状态。调用仓库不能绕过这些检查。

原生任务和创意版本使用已有 created_by，素材使用 owner_user_id。self/team 不借用
其他权限的 tenant 范围，缺少可信团队绑定时仅能按本人拥有者访问；旧缺归属记录不回填。
设计任务的 SKU 关系不自动成为设计团队授权。完整团队模型仍需独立建设。

| 操作 | 所需权限及对象 |
| --- | --- |
| 创建任务 | design:read、design:write；实际 SKU 的 product:read |
| 任务读取、列表 | 任务拥有者的 design:read |
| 版本及附件历史 | 任务 design:read，各素材 asset:read |
| 新版本 | 任务 design:read/write，所选素材 asset:read |
| 审核、主版本 | 任务 design:read/review，所选素材 asset:read；不要求 design:write |
| 权属确认、原生推广入口 | 素材 asset:read/promote |
| 正式 SKU 绑定 | 创意版本 design:read/write/review、规格 design:read、素材 asset:read、实际 SKU product:read |
| 创意读取、审核 | 创意拥有者 design:read，审核另需 design:review；每个素材 asset:read |
| 版本文件签名 | 任务 design:read、素材 asset:read，签名后再次检查 |

订单域还需 order:read 与 order:pii:read 各自当前 tenant 范围。含订单私有文件的任务
在父级列表、直达、版本及签名上保持同一门禁，不因只展示任务元数据而绕过私有范围。
显式非成员凭据保留服务器授予的权限上限，不将其当作个人登录验收。

## 版本、审核和来源

新版本在父任务锁内分配版本号，仍创建新记录；已有批准版的内容和原文件关联不可覆盖。
直接审核必须仍为 pending_review；旧审核不能以未更新的批准版伪装成功。
主版本必须属于本任务且已批准，在更新事务内复核素材当前权属、保留状态和期限。
审核角色可以只具备读取、审核及素材读取，不隐式授予写入权限。

当前权属状态撤回、文件软删除、来源不符或明确期限到期时，不能新建可用版本、批准或签名。
期限以数据库时钟判断，服务外层的早期读取不代替事务内复核。文件历史保留原 ID、SHA
和关联，软删除不制造新的批准事实，也不签发新链接。

研究域证据不能通过改写权属字段或传入伪造元数据转为授权素材；订单原图也不能推广到
通用授权域。自有原件使用既有授权素材入口导入。原生推广读取实际存储记录，合法授权
素材返回原记录；它不再复制研究或订单对象。来源及权属说明不能扩大工具权限。

## 创意审核和真实交接

新发生的创意审核保持母版和全部规格完整性检查，复核操作者、创意拥有者和每个素材。
批准时记录实际审批时间和操作者，保留已有有效批准依据及其他元数据；文件内容版本
不因权属说明改变而升级。自有/AI 来源缺少说明引用时，当前明确审核以
creative-review:版本ID 标识这次实际决定，不伪称原授权合同；许可/委托资料仍需明确引用。
旧批准记录缺失的证据不自动补写，模型候选也不自行批准。

原生 SKU 绑定在同一事务复核创意批准、版本拥有者、实际商品范围、规格与素材固定版本。
合法重放保留原 ID；当前读取或写入范围失效不能通过既有绑定绕过。整批目标校验失败
不能留下部分正式设计。保存后的审核与主版本选择不代表 Listing 已发布或工厂已接受。

私有签名使用数据库中的实际素材，不信任调用方提供的 objectKey、域、版本或 SHA。
返回前再检查素材和父任务，操作审计后的资料返回也复核当前读取权。
已交付的最长 600 秒 URL 和已下载字节不能被召回；此边界沿用[素材契约](asset-authority.md)。

## 实测与剩余

原生设计专项36项与现有创意/制作回归54项通过，去掉重复的两项原生设计后为88项。
覆盖真实成员、RLS、私有存储、签名下载、实际创意审批到 SKU 和正式设计的交接。
最初19项失败真实反映权限、状态和来源问题；并发编号用例在旧版也通过，不作为竞争已复现的证据。
增加数据库时钟时曾误用未完成的查询构造器，修复后专项通过，未计入最初业务缺陷。

真实浏览器的最终结果、正常运行和清理见[本批交付](../project-control/NATIVE_DESIGN_AUTHORITY_DELIVERY_20261019.md)。
其他画布/POD 命令、生产编辑拥有者、可信团队、正式身份/网络部署、真实模型质量、
来源旧记录处置及完整 B06/B08/B15/B18 仍需继续；本批不能替代全平台或正式发布验收。
