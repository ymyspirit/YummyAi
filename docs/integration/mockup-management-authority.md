# 套图管理的当前授权与审核依据

2026-10-19 · PRD 1.1.24，关联 B15/B18/B28。106 项关联隔离集成、全仓回归、桌面/手机及独立生产构建已有本地证据；临时文件与版本包以本批最终检查点为准。完整平台、正常部署和业务验收继续。

## 对象和来源

管理命令在所属租户事务内重新读取当前成员，并与传入权限上限逐项取交集。检查记录按原申请人、批次按创建人、模板包按同一家族首个版本的创建人授权。协作者新增版本不改变家族归属，无可信团队归属的旧对象不因无关宽权限而开放。

列表在分页限制前过滤自己的对象。选项另外检查 PSD/编译文件、正式设计的上游创作版本、SKU、销售配方、规格及目标 Listing 各自的读取或写入范围。历史读取与新操作分别处理；原件过期、撤权或生产来源归档不会得到新操作授权。

API 与实际 Worker 复用 catalog-core 的检查，不建立第二套设计或商品事实。原五类执行输入指纹的结构保持兼容，既有原执行、费用、检查点和产物不回填、不重置。

## 人工确认和审核

`GET /v1/pod/mockup-template-inspections/:id` 返回 `reviewFingerprint` 及 `executionEvidence`。确认入口必须提交 `{ expectedFingerprint }`。同一检查结果重复确认保留第一次确认者和时间，来源校验与审计在同一事务完成。

`GET /v1/pod/mockup-batches/:id` 为每一款返回当前 `reviewFingerprint`。审核的每一项必须携带 `itemId`、`decision` 和 `expectedFingerprint`；驳回另需原因。批次、条目和最新产物在事务内锁定。结果身份、尝试、版本、校验值或审核状态改变时返回冲突，不能批准未看过的新产物。有槽位尚在运行时不能整款审核。

批准核对实际产物与原模板/正式设计的关系、当前许可、文件版本和校验值，并比对原不可变完成凭据中采用的资产。资产权利确认由既有治理服务执行，与条目状态和审计一同提交；审计失败会回滚全部变更。

界面把勾选时的审核依据固定在本地。刷新结果不会替换勾选依据；结果变化时显示提示并要求取消勾选、重新查看。刷新不提交生成任务。

## 历史边界

无原执行的模板编译资料明确标为 `legacy_compilation`，人工复核当前源文件、编译清单和黄金图后才可用于新模板包。存在原执行时必须证明其完整交接，不能降级为历史豁免。

历史套图产物缺少原完成凭据时不能获得新的批准或 Listing 候选绑定。可读历史保留；操作者驳回后创建新尝试，由实际原生渲染获得新的完成凭据。已有 Listing 绑定和不可变导出不被改写。

普通单素材绑定入口拒绝套图产物，整款映射入口复核当前 Listing 草稿、目标归属、全部必需槽位和最新受审产物，避免绕过整款检查。此处只创建候选，不发布平台。

## 并发和恢复

PSD 检查按源文件版本、槽位与编译版本串行去重。套图新请求的内容摘要纳入申请人，同一人的同一依据复用原批次；另一申请人不能获得原请求的执行身份。

重试先锁定批次及最新槽位尝试。旧尝试、取消批次和超限尝试明确拒绝；允许重试时新增尝试与原执行，不重置旧完成记录。排队失败更新实际仍排队的条目及批次计数；已取消或已执行的状态不被失败回执覆盖。

## 验证和剩余项

`creative-owner-consumers.integration.test.ts` 使用实际 RLS、私有存储、扫描、PSD 编译和 ImageMagick 渲染，外部生图传输为合成。新增断言覆盖确认去重、撤权、替换未采用资产、许可过期、审计回滚、并发重试/审核、家族归属、申请人去重和 Listing 目标范围。

`pod-batch-promotion.integration.test.ts` 保留历史元数据读取，验证缺少原完成凭据时不新增候选。原生渲染后的完整批准与候选绑定由前述真实消费者测试覆盖。

桌面/390px 的实际浏览器覆盖脚本延迟、刷新冲突、保留驳回草稿、黄金图加载失败及恢复、历史缺原交接拦截、过期来源的历史视图和撤权清图。研究/竞品页面额外导出读取函数的问题已通过移入功能模块修正，保留原读取行为；生产构建及这两页的实际读取回归通过。

本批单元覆盖累计 2032 项，最终 Web 754/契约 258；全仓隔离 1335 个断言包含重复 API 单元 318，实际集成 1017，末次 106 关联集成补验后续投影调整。浏览器使用隔离开发快照，生产构建独立执行；个人真实身份、真实提供方和正式发布不由此代替。15 组隔离资源、9 个浏览器快照及 3 个构建快照均另有独立不存在核验。清理与版本包见本批最终检查点，普通 API/Web 未切换，普通 Worker 不消费积压任务。
