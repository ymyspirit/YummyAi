# 上架商品组合与订单制作来源

工作台顺序：载体与工艺 → 印花设计 → 商品组合 → 套图与文案 → 刊登审核。
研究与定位资料保留在辅助依据区。审核、平台接受与实际可售继续读取各自真实状态。
[Amazon Custom](https://sell.amazon.com/programs/custom) 使用 FBM；正式发布沿用已授权店铺的 API 流程。

SPU 描述可定制载体与工艺能力；规格固定制造底稿、模板、包装资料及其版本。
印花 SKU 描述原创主图、素材、顾客图片/文字字段、制作布局和规则。
销售 SKU 固定一个 SPU 规格与一组印花绑定；销售方案固定选中的销售 SKU、套图、文案、价格、定制字段及渠道资料。

`printBindings` 含绑定 key、artworkVersionId、front/back 制作面、region、百分比区域和本地字段到顾客字段映射。
一件商品可同时采用正反面不同印花，也可采用固定装饰加顾客来图或文字。
不同印花需要独立的顾客字段键；文字条件和生产区域按映射共同保存。显式背面使用自己的内容，旧未指定面图层保持原镜像规则。
制作编辑器按正面和独立背面显示图层，背面刀线与条码框保持镜像。独立背面图层可调整位置、内容并保存新版本；沿用镜像规则的图层在正面编辑，在正反片排版中检查完整背面。单面工艺的背片继续留白。
`artworkVersionId` 单印花输入继续兼容；历史配方按原语义读取，不回填组合或今天的制作规则。
组合身份包括印花主档、顺序、面、区域、布局和字段映射；只升级版本可修订配方，改变组合身份则新建销售 SKU。
新配方、资料包及套图均固定全部印花版本，任一印花变更会触发重新核对。旧订单与旧包继续读取旧快照。

多个图案供顾客选款使用销售方案 `patternChoices`。每个选款固定内部销售 SKU 和制作配方，默认作为 Amazon Custom 选项。
同一真实规格共用平台 SKU；`custom_sales_sku_mapping` 保存平台 SKU 与 Custom 值到内部销售 SKU 的映射。
规格变体仍按实际类目配置。封存包包含每个 SKU 的完整印花组合、规格版本、定制定义、布局和平台/选款映射。
渠道登记须与受控封存映射一致。订单按店铺、站点、平台 SKU、顾客选款、下单时间匹配生效版本；缺项或歧义进入审单。
选款是路由字段，保留在订单需求中，不作为生产文字；只剔除已固定且完全匹配的选款值。

订单复制已授权固定印花和通用模板到订单私有域，再读取本单顾客素材生成制作任务。
顾客素材不能进入印花库或上架包。来图模板确认、运营审核、工厂接受和正式生产放行是独立记录。
商品套图仍需对应已审核制作版本；定制商品主图需真实成品照片。异形抱枕销售样例也接受通过原门禁的正式 JPG，其他产品沿用供应商格式。

迁移 `0105_sales_compositions.sql` 保存不可变数组及选款渠道索引。集成覆盖组合修订、旧单覆盖兼容、选款匹配及私有素材边界。
