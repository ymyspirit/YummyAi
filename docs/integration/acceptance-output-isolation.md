# 验收输出隔离

2026-10-20 · 关联 R39/R41/R43、B09/B28/B51。执行器复用现有 Playwright、Vitest 和一次性服务资源，不改变普通 ERP 或业务命令。

`run-order-daily-acceptance.mts` 在创建数据库、桶、Redis、身份夹具和运行清单前，通过 `prepareAcceptanceOutput` 验证输出路径。`YUMMYAI_TEST_CACHE_DIR` 现在表示工作区 `tmp` 内的父目录；每次调用都创建新的 `order-daily-artifacts-<nonce>` 缓存目录和 `output-ownership.json`。重复使用父目录不会复用旧缓存。

浏览器分支始终传入有效的 `--output`，覆盖各套件原有的静态配置。默认产物进入本次缓存目录下的 `playwright`；显式指定的输出也必须在工作区 `tmp` 内、尚不存在且不包含本次缓存目录。已有输出、重复/缺失参数、链接祖先、越界目录和历史冻结路径在创建目录及业务测试资源前拒绝。当前冻结清单从项目状态引用的保护记录读取。其原目录、父子范围均不得作为产物目标。

转换缓存、last-run和内置文件报告的环境输出定位到本次拥有的目录。一次性执行器拒绝依赖旧状态的`--last-failed`及`--last-failed-file`；重验使用新运行及用例筛选。非浏览器分支继续使用原工具参数，包括备份工具的`--output-root`，不注入Playwright专用参数。

[Playwright CLI](https://playwright.dev/docs/test-cli)定义命令行产物目录。本实现通过真实CLI验证静态`outputDir`不会删写旧哨兵，TypeScript转换缓存和last-run进入独立路径；另用真实编译版身份套件及数据库集成检验实际执行器。

范围是标准缓存与Playwright内置产物位置；自定义测试、报告器或辅助程序直接写文件仍须独立声明归属并检查，不把此工具视为任意代码文件系统沙箱。当前普通候选正在使用的共享缓存不属于可随测试清理的独占资源。

测试结束后先核对运行清单和拥有权回执、数据库/桶/Redis实际不存在，再删除本批独占的日志、图片、trace、下载、转换缓存和清单。资源清理不代表本地文件已删；旧冻结目标继续保留。首次身份测试误写旧目录的历史例外不因本修复被追溯标作已清理。

这项修复不等于生产命令已经支持跨刷新恢复。后者的服务端原请求、当前权限、事务回执与执行凭据要求见[持久恢复设计](../architecture/order-command-recovery.md)，尚待实现和业务验证。
