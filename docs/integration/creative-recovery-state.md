## 已确认的问题

图片/视频草稿第一次保存A的回执丢失后，controller进入失败态；继续输入B只更新controller，不再更新storage的本地副本。只读核对发现A已提交时，storage可能按旧A清除未保存警告，B仍未落库；没有B时，controller的失败态也可能在A确认后继续阻断复制。

设计与套图批次取消后，迟到原任务的失败回调仍可进入聚合更新，将已取消的父批次改回失败或待审核。取消不是任务失败，也不能因派生统计而失效。

交叉审查另确认：首次保存若在350ms队列内被同owner撤销save，尚未派发的失败会留下无法解除的保存阻断。权限恢复必须有保留原稿并明确保存的出口，不能借此重发未知结果请求。

共享媒体和删除入口也有同类预检缺口：消费旧证明后，若在派发前失去保存权限，不能丢失恢复依据；未保存的本地Blob不能因指针相同被当作只读hydration成功。

## 保存与核对契约

- 每次编辑同步登记当前owner、namespace/key、最新文档和编辑代次；登记只改变本地状态，不发送保存请求。原未知尝试A的正文和原CAS revision固定，后来核对得到的可用CAS基线单独保存。
- `studio.storage` 保留实际I/O的 `pending` 和 `error`，增加非负整数 `dirty`，表示仍未确认的本地文档数。旧运行时省略该字段时按0兼容。宿主校验状态消息，不把非法计数归零，不以pending=0或error=null推断当前文档已保存。
- 核对只读取原地址和原尝试结果。A已提交且当前还是A时，两层可确认干净且不追加写；A已提交而当前为B时，仅确认A，B继续未保存，结果为unchanged，复制/离页继续受阻。原版本未变时也只提供明确保存的依据，不自动写B。
- 明确未派发与结果未知分开记录。前者只在当前owner、原失败记录和原CAS均经只读核对保持一致后授权明确保存，不调用已保存确认；远端已变、读取失败或归属失效均不授权。已有A证明不能替代后来未派发B的新核对。进入RPC后的失败始终保留未知分类。
- 工作台和原生媒体/删除重试共用当前owner下的预检恢复边界；原set/remove操作与已证CAS均固定。RPC前失败重新留下需要核对的记录，RPC后未知不能降级。只读no-op只接受已确认的原记录，dirty或恢复中的本地副本不算保存成功。
- 原尝试与最新本地意图分开保存。未知删除后重新输入B，或未知保存后明确删除，都只登记本地set/remove及代次；核对仍只证明原尝试，明确保存执行最新已接受意图。回执须匹配实际发送的操作与代次才能清dirty，不能因set(null)与remove的值相同而混同。媒体删除与写入均核对当前mediaWrite，拒权不接受新本地意图。
- 其他版本、读取失败或权限/归属变化不授权覆盖。两处“明确保存”沿同一按owner/地址/原尝试核对的入口；某一份草稿的证明不能授权另一份。保存B期间再输入C时，B的回执不能确认C。
- 普通工具切换与组件卸载不释放同owner的草稿登记及flush职责；CLEAR、真实owner变化或撤权不得被迟到核对/保存结果复活。核对不能替换当前输入、重新发送A、重新生成素材或调用付费模型。

## 取消与迟到任务

原业务拥有者在更新条目或重算批次之前，以与取消入口一致的父到子顺序取得父锁并重查取消/归档终态。迟到原任务可以保留自己的执行、响应和费用事实，但不能更改已取消父批次或条目，不能生成新产物或解除取消围栏。设计和套图分别覆盖，不能只在前置读取中加一次判断。

## 验证与范围

先使用真实controller与storage联动的失ACK回归，以及真实隔离数据库中的取消→迟到原任务回归，证明旧实现失败；再修实现。覆盖A已提交/未提交、有无B、并发新稿、冲突、迟到撤权、工具卸载、明确保存后的完整flush和重新读取。浏览器以实际宿主未保存警告、只读核对零写、明确保存及刷新读回为准。所有测试使用隔离业务资源并按所有权清理输出，保留源测试及精简结论。

本片不宣称完整C01—C08、H01—H12或全平台完成。创作执行终态找回原响应后的安全采用入口，以及批量设计驳回后的同族修订，是另外两项已发现的真实缺口；不将现有“登记响应摘要”或“重新选中同一候选”冒称这些能力已实现。

## 隔离验收入口

继续使用 `tools/scripts/run-order-daily-acceptance.mts` 的一次性资源生命周期。`--suite=creative-recovery-integration` 只运行取消终态专项；`--suite=studio-draft-recovery-browser --compiled-web --candidate=<已核验ID>` 使用同源 Web 候选和显式 `E2E_STUDIO_RUNTIME_MANIFEST` 指定的封存运行时。不得从开发树连接普通业务库验收。

浏览器夹具先按真实 CAS 删除本次测试文档，再取消、归档并核对两个合成项目；失败仍须返回失败，不以外层删除一次性数据库代替业务清理。外层随后关闭身份和运行时服务，删除 DB、桶和 Redis，主控独立复核不存在，目视检查截图后才清理自有原始输出。
