# 固定制造清单与工厂接受回执

2026-10-19 · PRD 1.1.33 · 本地增量实施，关联 R12/R25、B33/B35/B36/B37。完整 48 项需求、54 个工作包、8 个阶段保持。普通环境尚未采用 0133—0135，不代表真实工厂接受或平台完成。

## 固定什么

新交付包使用 V3。订单拥有者从确切生产版本的不可变制造绑定读取原已批准制造版本、原规格、来源修订、销售 SKU 的数量和件/双/套单位；检查原 BOM 内容与校验值后生成确定性工厂清单。今日模板、目录映射或知识条目变化不能替换原生产依据。缺制造绑定的历史生产仍显示缺项，不能从当前模板猜补后生成新 V3 包。

工厂清单明确列出制造编码、名称、版本、数量、产出单位、材料编码与名称、材料基本单位、每份精确耗量、损耗口径、本单计划分数用量、供料责任、顺序工序及执行责任。精确分数的分子和分母使用整数字符串，避免浮点误差；展示的是备料计划，不是实际领料、耗用、库存预留或产能承诺。本单生产说明仅取生产单中明确记录的说明。

工厂视图通过严格投影返回上述最小内容及清单校验值，不返回库存主键、库存余额、成本、内部 BOM 备注、工时估计、内部商品主键或买家地址。内部绑定 ID、原完整 BOM 指纹和来源修订留在订单拥有者及加密包快照中，不通过工厂最小视图暴露。生产单说明可能包含操作员明确交付的制作要求，因此不能把内部 BOM 备注自动复制为说明。

## 文件和接受

V3 ZIP 在原 `manifest.json`、商品交付清单、交付说明及正式 JPG 外，增加 `制造材料清单.csv`、`制造工序清单.csv`、`本单生产说明.csv`。V3 的 manifest 字节及包校验值使用同一规范 JSON；CSV 对含前导空白的公式前缀也作转义。正式 JPG 保持实际原字节，仍执行原工艺、规则快照、实际文件及下载后验检查，不修改像素或 DPI。

工厂或受权运营人员分别记录收到、接受或拒收。新 V3 的“接受文件”必须携带看到的制造清单 `manufacturingChecksum`，同时核对原文件 SHA-256、数量、顺序和当前任务权限；缺值或错值不推进状态。收到文件不等于接受，接受不等于完工、质检通过、可发货或真实生产放行。

新包创建、原回执、状态里程碑和审计同笔提交，审计失败整笔回滚。恢复原成功请求要求当前权限、原操作员、原正文及原请求编号一致，不追加重复审计或重复接受。实际数据读取、存储 I/O 后及下载返回前继续沿用当前对象授权、期限、暂停和撤权复查。当前工厂分配只授权对应任务及最小清单。

## 数据与历史

`0135_manufacturing_delivery.sql` 登记 V3 和交付商品上的制造绑定、原 BOM 内容指纹、工厂计划指纹。租户组合外键绑定确切生产版本，插入触发器要求新 V3 在原创建事务封存匹配元数据，延迟约束阻止空 V3 包提交。普通应用新建包不能降级为 V1/V2。不可变包、商品与回执仍禁止原地更新或删除。

历史 V1/V2 的原密文、manifest 及旧校验算法不改写；新增元数据保持 NULL。即使历史生产已有制造绑定，也不为旧交付包补造制造清单。新增回执字段可选且没有默认值，避免改变旧请求正文和幂等指纹。旧包仍按其原版本解释和恢复，历史缺项明确可见。恢复演练必须另行验证，开发迁移通过不代替正式采用。

## 入口与验证边界

运营入口沿用生产中心的工厂交付与回执；工厂入口沿用个人身份任务详情。两处共用密集制造清单组件，长名称、分数及校验值可换行，手机单列、桌面双列，尊重减少动态效果。工厂个人身份浏览器已走真实 OIDC、BFF、REST、数据库和原 JPG 下载路径；使用合成账户，不代表用户本人会话或真实工厂业务。

可复跑的隔离命令（先为每次运行设置全新 `YUMMYAI_TEST_CACHE_DIR`，浏览器显式设置全新 `--output`）：

```powershell
pnpm test:e2e:order-daily --suite=product-authority-integration src/orders/order-production-delivery.integration.test.ts --cache=false
pnpm test:e2e:order-daily --suite=manufacturing-upgrade-integration --cache=false
pnpm test:e2e:order-daily --suite=manufacturing-delivery-upgrade-integration --cache=false
pnpm test:e2e:order-daily --suite=factory-portal '--grep=personal login downloads' --output=<本次全新输出目录>
```

前两类历史升级分别从真实 pre-0134 和 pre-0135 迁移建立 V1/V2，再升级；比较原记录字节、指纹和不补造历史。历史文件为不可恢复的合成元数据，不能据此宣称文件质量或工厂接受。实际原 JPG 由独立浏览器场景验证。
